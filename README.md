| Реформы и реформаторы | 📝 зачёт | ✅ **да, при 60+** | 8 очных практик × 5 + 8 лекций × 1 + 7 дистанционных × 4 = **76 максимум**. Не хватает до 60 → тест с прокторингом (до 24). [Подробно](./history) |

**Как считается итог (БаРС).** За семестр максимум 103 балла (100 + 3 дополнительных). Оценка: **60–73 → «удовл.», 74–89 → «хорошо», 90+ → «отлично»**; для зачёта нужно ≥ 60 и закрытые **ключевые** контрольные точки. На экзамен обычно приходится 20–40 баллов, в зависимости от разбалловки предмета (80/20, 70/30 или 60/40). Без экзамена максимум 60–80 баллов, поэтому «автомат» бывает, только если преподаватель его явно предусмотрел.

## 🗂️ Структура репозитория <a name="structure"></a>

```
ITMO_Student_FeschenkoAE/
├── programming/        💻 Программирование (Java)
│   ├── code/           проект IntelliJ: src/Main.java
│   ├── lab1/           task/ · guide/ · report/
│   ├── lectures/       слайды и конспект
│   └── books/          методичка Гаврилова
├── opd/                🖥️ ОПД: lectures/ · manuals/ · lab1/
├── informatics/        🔢 Информатика
│   ├── code/           Python-проект
│   ├── lab1/ lab2/     задания, отчёты, теория, вопросы
│   ├── annotations/    аннотации + шаблон
│   └── lectures/
├── algebra/            📐 practice/ · homework/ · rgr/ · project-work/
├── calculus/           📈 books/ · homework/
├── discrete-math/      🧮
├── history/            🏛️ lectures/ · books/ · online/ + справка по баллам
├── english/            🇬🇧 books/
├── physical-education/ 🏃 экстернат: чек-лист и нормативы
├── _templates/         титульник отчёта
├── _screens/           скрины учебного плана из ИСУ
├── РЕЖИМ.md            расписание недели и будильники
└── STUDY_NOTES.md      рабочие заметки: дедлайны, статусы, договорённости
```

Внутри каждой лабы одинаковая схема: `task/` (задание) → `guide/` (разбор) → `report/` (отчёт). У каждого предмета есть свой `README.md` с оглавлением.
