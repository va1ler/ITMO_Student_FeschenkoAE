### 🎯 Автоматы: где можно закрыть без экзамена или зачётного мероприятия

| Предмет | Итог | Автомат | Условия и что известно |
|---|---|---|---|
| Информатика | 🔴 экзамен | ✅ **можно** | автомат = все баллы × 0.17 (экзамен до 20 баллов); нужно закрыть **оба теста в ЦДО, минимум по 6 баллов** за каждый. Главное: все 7 лаб в срок и аннотации (до 2 баллов + 1.25 за посещение каждая). Правило прошлых лет, сверить в [канале курса](https://t.me/balakshin_students) |
| Основы профессиональной деятельности | 📝 зачёт | ❌ **нет** | по методичке зачёт — **ключевая точка на 40 баллов (минимум 24)**, сдаётся по билетам обязательно. До него: ЛР1 (10), ЛР2 (30), контрольная (10), 2 теста (по 5) |
| Программирование | 📝 зачёт | ❌ **нет** | по лекции Гаврилова: **зачёт — отдельное мероприятие (12–20 баллов)**, плюс контрольная (12–20). Лабы 3 (4) шт. дают 36–60 баллов, все **обязательны**. Сдано, если 60+ |
| Алгебра и алгоритмы (баз.) | 🔴 экзамен | ❔ | по правилам ИТМО автомат только если преподаватель сам объявил условия. Спросить на практике |
| Математический анализ (баз.) | 🔴 экзамен | ❔ | то же: спросить у практика условия автомата |
| Основы дискретной математики (баз.) | 📝 зачёт | ❔ | спросить Полякова, ставится ли зачёт по баллам за семестр |
| Реформы и реформаторы | 📝 зачёт | ❔ | обычно по баллам за практики и тесты. Уточнить на семинаре |
| English B1.1 | 📝 зачёт | ✅ по баллам | по опыту прошлых лет зачёт ставится по сумме баллов за семестр (≥ 60) |
| Физкультура | 📝 зачёт | ✅ по посещениям | закрывается набором занятий, отдельного зачёта нет |

**Как считается итог (БаРС).** За семестр максимум 103 балла (100 + 3 дополнительных). Оценка: **60–73 → «удовл.», 74–89 → «хорошо», 90+ → «отлично»**; для зачёта нужно ≥ 60 и закрытые **ключевые** контрольные точки. На экзамен обычно приходится 20–40 баллов, в зависимости от разбалловки предмета (80/20, 70/30 или 60/40). Без экзамена максимум 60–80 баллов, поэтому «автомат» бывает, только если преподаватель его явно предусмотрел.
