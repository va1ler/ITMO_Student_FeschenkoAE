## Часть 1. Вычисление пределов (Демидович)

### Главный приём: делим на старшую степень
Если числитель и знаменатель — многочлены от n, **делим всё на старшую степень n в знаменателе**. Потом используем, что $\frac{c}{n^k} \to 0$ при $k>0$.
Итог определяется степенями:
- степени равны → предел равен отношению старших коэффициентов;
- степень числителя меньше → 0;
- степень числителя больше → ∞.

| № | Предел | Подсказка |
|---|---|---|
| 1.231 | $\lim \frac{n-1}{3n}$ | степени равны |
| 1.232 | $\lim \frac{5n+1}{7-9n}$ | осторожно со знаком |
| 1.233 | $\lim \frac{(n+1)^2}{2n^3}$ | сравни степени |
| 1.235 | $\lim \frac{(n+2)^3-(n-2)^3}{95n^3+39n}$ | сначала раскрой числитель: $n^3$ сокращается! |
| 1.237 | $\lim \frac{\sqrt[3]{n^4+3n+1}}{n-1}$ | какая «степень» у корня? |
| 1.242 | $\lim \frac{1^2+2^2+\ldots+n^2}{n^3}$ | формула суммы квадратов |
| 1.244 | $\lim \left(\frac{1}{1\cdot2}+\frac{1}{2\cdot3}+\ldots+\frac{1}{n(n+1)}\right)$ | $\frac{1}{k(k+1)} = \frac1k - \frac1{k+1}$ |

<details><summary>1.231 → 1/3</summary>

$$\frac{n-1}{3n} = \frac{1-\frac1n}{3} \to \frac{1}{3}$$
</details>

<details><summary>1.232 → −5/9</summary>

$$\frac{5n+1}{7-9n} = \frac{5+\frac1n}{\frac7n-9} \to \frac{5}{-9} = -\frac59$$
</details>

<details><summary>1.233 → 0</summary>

$$\frac{(n+1)^2}{2n^3} = \frac{n^2+2n+1}{2n^3} = \frac{\frac1n+\frac2{n^2}+\frac1{n^3}}{2} \to 0$$
Степень числителя 2 < 3.
</details>

<details><summary>1.235 → 0</summary>

Раскрываем по формуле $(a+b)^3-(a-b)^3 = 6a^2b+2b^3$ при $a=n$, $b=2$:
$$(n+2)^3-(n-2)^3 = 12n^2+16.$$
Тогда
$$\frac{12n^2+16}{95n^3+39n} = \frac{\frac{12}{n}+\frac{16}{n^3}}{95+\frac{39}{n^2}} \to \frac{0}{95} = 0.$$
Ловушка: если не раскрыть скобки, покажется, что старшие степени числителя и знаменателя обе равны 3, и можно ошибочно получить ненулевой ответ. На самом деле $n^3$ в числителе сокращается.
</details>

<details><summary>1.237 → +∞</summary>

$\sqrt[3]{n^4+3n+1} = n^{4/3}\sqrt[3]{1+\frac{3}{n^3}+\frac1{n^4}}$, знаменатель $n-1 = n(1-\frac1n)$:
$$\frac{n^{4/3}\sqrt[3]{1+\ldots}}{n(1-\frac1n)} = n^{1/3}\cdot\frac{\sqrt[3]{1+\ldots}}{1-\frac1n} \to +\infty,$$
потому что $n^{1/3}\to\infty$, а дробь стремится к 1. Степень числителя 4/3 > 1.
</details>

<details><summary>1.242 → 1/3</summary>

$$1^2+2^2+\ldots+n^2 = \frac{n(n+1)(2n+1)}{6}$$
$$\frac{n(n+1)(2n+1)}{6n^3} = \frac{1}{6}\cdot 1\cdot\left(1+\tfrac1n\right)\left(2+\tfrac1n\right) \to \frac{1\cdot2}{6} = \frac13$$
</details>

<details><summary>1.244 → 1</summary>

Сумма «телескопическая»: $\frac{1}{k(k+1)} = \frac1k-\frac1{k+1}$, и соседние слагаемые сокращаются:
$$\left(1-\tfrac12\right)+\left(\tfrac12-\tfrac13\right)+\ldots+\left(\tfrac1n-\tfrac1{n+1}\right) = 1-\frac{1}{n+1} \to 1$$
</details>

## Часть 2. Доказательства по определению (`limits.pdf`)

### Определения — выучи дословно
**Конечный предел:** $\lim x_n = a \iff \forall\varepsilon>0\ \exists N(\varepsilon)\ \forall n>N:\ |x_n-a|<\varepsilon$.
**Бесконечный предел:** $\lim x_n = \infty \iff \forall E>0\ \exists N(E)\ \forall n>N:\ |x_n|>E$.

### Шаблон доказательства (для задания 1)
1. Пишем $|x_n - a|$ и упрощаем.
2. Если нужно, **оцениваем сверху** чем-то простым: $|x_n - a| \le \frac{C}{n}$. Грубая оценка допустима, лишь бы она была верной.
3. Решаем неравенство «простое < ε» относительно n → получаем $n > \ldots$.
4. Берём $N(\varepsilon) = \left[\ldots\right]$ (целая часть) и пишем вывод: «при $n>N$ выполнено $|x_n-a|<\varepsilon$, что и требовалось».

### Задание 1

<details><summary>1) 3/(n+2) → 0</summary>

$\left|\frac{3}{n+2}-0\right| = \frac{3}{n+2} < \varepsilon \iff n > \frac3\varepsilon - 2$. Берём $N(\varepsilon) = \left[\frac3\varepsilon\right]$: при $n > N$ имеем $n+2 > \frac3\varepsilon$, то есть $\frac{3}{n+2} < \varepsilon$. ∎
</details>

<details><summary>2) (n−1)/(n+1) → 1</summary>

$\left|\frac{n-1}{n+1}-1\right| = \left|\frac{-2}{n+1}\right| = \frac{2}{n+1} < \varepsilon \iff n > \frac2\varepsilon - 1$. $N(\varepsilon) = \left[\frac2\varepsilon\right]$. ∎
</details>

<details><summary>3) (−1)ⁿ/n² → 0</summary>

$\left|\frac{(-1)^n}{n^2}\right| = \frac{1}{n^2} < \varepsilon \iff n > \frac{1}{\sqrt\varepsilon}$. $N(\varepsilon) = \left[\frac{1}{\sqrt\varepsilon}\right]$. ∎
</details>

<details><summary>4) sin n / n → 0</summary>

Так как $|\sin n| \le 1$: $\left|\frac{\sin n}{n}\right| \le \frac1n < \varepsilon \iff n > \frac1\varepsilon$. $N(\varepsilon) = \left[\frac1\varepsilon\right]$. ∎
Здесь работает приём «оценка сверху»: синус не решишь как неравенство, но он ограничен.
</details>

<details><summary>5) n·cos n/(n²+1) → 0</summary>

$\left|\frac{n\cos n}{n^2+1}\right| \le \frac{n}{n^2+1} < \frac{n}{n^2} = \frac1n < \varepsilon$ при $n > \frac1\varepsilon$. $N(\varepsilon) = \left[\frac1\varepsilon\right]$. ∎
</details>

<details><summary>6) n/2ⁿ → 0</summary>

По биному Ньютона при $n\ge2$: $2^n = (1+1)^n \ge C_n^2 = \frac{n(n-1)}{2}$. Тогда
$$0 < \frac{n}{2^n} \le \frac{n}{\frac{n(n-1)}{2}} = \frac{2}{n-1} < \varepsilon \iff n > 1+\frac2\varepsilon.$$
$N(\varepsilon) = \left[1+\frac2\varepsilon\right]$. ∎
</details>

<details><summary>7) ⁿ√2 → 1</summary>

Обозначим $\alpha_n = \sqrt[n]2 - 1 > 0$. Тогда $2 = (1+\alpha_n)^n \ge 1 + n\alpha_n$ (неравенство Бернулли), откуда $n\alpha_n \le 1$, то есть $\alpha_n \le \frac1n$. Значит, $|\sqrt[n]2 - 1| = \alpha_n \le \frac1n < \varepsilon$ при $n > \frac1\varepsilon$. $N(\varepsilon) = \left[\frac1\varepsilon\right]$. ∎
</details>

### Задание 2 (предел = ∞)
Шаблон тот же, но теперь нужно показать $|x_n| > E$, поэтому **оцениваем снизу**.

<details><summary>1) n² − 1 → ∞</summary>

$n^2 - 1 > E \iff n > \sqrt{E+1}$. $N(E) = \left[\sqrt{E+1}\right]$. ∎
</details>

<details><summary>2) √n → ∞</summary>

$\sqrt n > E \iff n > E^2$. $N(E) = [E^2]$. ∎
</details>

<details><summary>3) (n² − 3)/(n+1) → ∞</summary>

Выделим целую часть: $\frac{n^2-3}{n+1} = (n-1) - \frac{2}{n+1}$. Так как $\frac2{n+1} \le 1$, получаем $\frac{n^2-3}{n+1} \ge n-2 > E$ при $n > E+2$. $N(E) = [E]+2$. ∎
</details>

<details><summary>4) (n² + (−1)ⁿn)/(n+2) → ∞</summary>

Так как $(-1)^n n \ge -n$: $\frac{n^2+(-1)^n n}{n+2} \ge \frac{n^2-n}{n+2} = (n-3) + \frac{6}{n+2} > n-3 > E$ при $n > E+3$. $N(E) = [E]+3$. ∎
Проверка деления: $(n+2)(n-3) = n^2 - n - 6$, остаток 6.
</details>

### Задание 3 (предела нет)
Главный приём: **если две подпоследовательности сходятся к разным числам, предела нет** (у сходящейся последовательности все подпоследовательности сходятся к одному пределу).

<details><summary>1) aₙ = 1 + (−1)ⁿ</summary>

Чётные номера: $a_{2k} = 2 \to 2$. Нечётные: $a_{2k+1} = 0 \to 0$. Пределы подпоследовательностей разные, $2\ne0$ → предела нет. ∎

Через определение: пусть $\lim a_n = a$. Возьмём $\varepsilon = 1$: с некоторого номера все $|a_n - a| < 1$. Но тогда $2 = |a_{2k} - a_{2k+1}| \le |a_{2k}-a| + |a-a_{2k+1}| < 2$ — противоречие.
</details>

<details><summary>2) aₙ = cos(2πn/3)</summary>

$n = 3k$: $a_n = \cos 2\pi k = 1$. $n = 3k+1$: $a_n = \cos\left(2\pi k + \frac{2\pi}3\right) = -\frac12$. Две подпоследовательности сходятся к $1$ и $-\frac12$ → предела нет. ∎
</details>
