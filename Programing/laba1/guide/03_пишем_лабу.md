# 03. Пишем лабу по шагам

Пишем в `ITMO_CODING_JAVA/src/Main.java`. После каждого шага запускаем программу и **коммитим** (`git add -A` → `git commit -m "..."` → Push).

## Шаг 1. Каркас и три метода-заглушки
Нужны: класс `Main`, метод `main`, `calculateElement(long li, double x)` (возвращает `double`) и `printMatrix(double[][] matrix)` (ничего не возвращает). Пока пусть `calculateElement` возвращает `0`, а `printMatrix` ничего не делает.
> Проверка: программа запускается и ничего не печатает. Коммит: «Лаба 1: каркас».

## Шаг 2. Массив `l`
`long[] l = new long[7];` и цикл `for`, который заполнит его значениями 16, 14, …, 4 (формула из файла 01). Временно выведи массив, чтобы проверить.
> 🤔 Почему в цикле счётчик `int i`, хотя массив `long`? (Индексы массивов всегда `int`.)

## Шаг 3. Массив `x`
`double[] x = new double[19];`, в цикле `x[i] = Math.random() * 15.0 - 2.0;`. Временно выведи и убедись, что все числа от −2 до 13.
> 🤔 Лучше писать `x.length`, а не `19` в условии цикла. Почему?

## Шаг 4. Двумерный массив `n` и двойной цикл
`double[][] n = new double[7][19];`. Внешний цикл идёт по строкам `i`, внутренний по столбцам `j`, внутри `n[i][j] = calculateElement(l[i], x[j]);`.
> 🤔 Почему в метод передаём `l[i]` и `x[j]`, а не `i` и `j`?

## Шаг 5. Метод `calculateElement`
Три ветки `if / else if / else`, формулы берём из таблицы в файле 01. В каждой ветке `return`.
> Помни про `3.0 / 4` и `Math.cbrt`.

## Шаг 6. Метод `printMatrix`
Двойной цикл, в нём `System.out.printf("%12.3f ", matrix[i][j]);`, после внутреннего цикла `System.out.println();`.
> Проверка: 7 строк по 19 чисел, в строках 16, 12 и 8 много `Infinity`.

## Шаг 7. Уборка
Убери временные выводы из шагов 2–3, проверь отступы (⌥⌘L в IntelliJ форматирует код), допиши короткие комментарии. Коммит: «Лаба 1: готово».
