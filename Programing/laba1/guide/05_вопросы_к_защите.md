## 1. Язык Java. Особенности языка
**Коротко:** Java — объектно-ориентированный, строго статически типизированный, кроссплатформенный язык. Код компилируется в байт-код, который исполняет виртуальная машина JVM.

**Подробнее:**
- **Кроссплатформенность** («write once, run anywhere»). `javac` выдаёт не машинный код, а байт-код, а JVM есть под каждую ОС. Один jar работает везде.
- **ООП:** весь код находится внутри классов.
- **Строгая статическая типизация:** тип каждой переменной известен при компиляции, ошибки типов ловит компилятор.
- **Автоматическое управление памятью:** сборщик мусора (Garbage Collector) сам удаляет объекты, на которые нет ссылок. Нет `free`/`delete`, как в C/C++.
- **Нет явных указателей и адресной арифметики**, есть ссылки. Это безопаснее.
- **JIT-компиляция:** JVM на лету компилирует часто выполняемый байт-код в машинный, поэтому Java быстрая.
- Богатая стандартная библиотека, многопоточность «из коробки».

💡 Мой jar собран на маке, а запускается на helios (FreeBSD) без перекомпиляции.

## 2. Средства разработки. JDK и JRE. Компиляция и выполнение. JAR-архивы
**Коротко:** JRE = JVM + стандартные библиотеки, это нужно для **запуска**. JDK = JRE + инструменты разработчика (`javac`, `jar`, `javadoc`, `javap`, отладчик), это нужно для **разработки**.

**Подробнее:**
- Цикл: исходник `.java` → `javac` → байт-код `.class` → JVM (`java`) исполняет.
- `javac Main.java` компилирует, `java Main` запускает класс, `javap -c Main.class` показывает байт-код.
- **JAR** (Java ARchive) — zip-архив с `.class` и ресурсами. Внутри лежит `META-INF/MANIFEST.MF`. Чтобы jar был **исполняемым**, в манифесте должна быть строка `Main-Class: <класс с main>`. Тогда его запускают командой `java -jar файл.jar`.
- Команда `jar cfe lab1.jar Main -C build .`: c = create, f = имя файла, e = entry point (главный класс).
- IDE (IntelliJ) — удобная оболочка над JDK: редактор, подсветка, отладчик, сборка кнопкой.

💡 Показать: `javac --release 17 -d build src/Main.java` → `jar cfe lab1.jar Main -C build .` → `java -jar lab1.jar`.

## 3. Примитивные типы данных. Приведение типов
**Коротко:** 8 примитивов: целые `byte`(8 бит), `short`(16), `int`(32), `long`(64); вещественные `float`(32), `double`(64); `char`(16 бит, беззнаковый, код символа Unicode); `boolean`(true/false).

**Подробнее:**
- Диапазоны: byte −128..127; short ±32 767; int ≈ ±2.1·10⁹; long ≈ ±9.2·10¹⁸.
- `char` в Java — целочисленный тип, по сути «беззнаковый short».
- **Преобразование (расширяющее, неявное)** без потерь: byte → short → int → long → float → double, char → int. Пример: `double d = 5;`.
- **Приведение (сужающее, явное)** с возможной потерей: `int t = (int) 9.99;` → 9, дробь отбрасывается. `(byte) 200` → −56 (переполнение).
- **Продвижение в выражениях:** byte/short/char в арифметике превращаются в int. Поэтому `byte c = a + b;` не компилируется, нужно `(byte)(a + b)`.
- Если в выражении есть `double`, всё выражение считается в `double`.

💡 `l` — массив `long`, `x` — `double`. При сравнении `l[i] == 10` число 10 (int) неявно расширяется до long. `3.0 / 4` дробное, а `3 / 4 == 0`.

## 4. Работа с переменными. Декларация. Инициализация. Присваивание
**Коротко:** декларация — объявить тип и имя (`int k;`). Инициализация — первое присваивание значения. Присваивание — запись нового значения (`k = 5;`).

**Подробнее:**
- Шаблон: `тип имя [= значение];`, например `double x = 2.5;`.
- Локальную переменную **нельзя использовать до инициализации**, это ошибка компиляции.
- Имя: буквы, цифры, `_`, `$`; не начинается с цифры; не ключевое слово. Регистр важен.
- **Константа** — `final double G = 9.81;`, значение присваивается один раз. Имена констант пишут ЗАГЛАВНЫМИ.
- **Область видимости** — блок `{ }`, в котором переменная объявлена. Переменная `i` из `for` видна только внутри цикла.
- `var` (с Java 10): тип выводится компилятором, `var s = 5;` даёт int.

💡 `long[] l = new long[7];` — декларация и инициализация в одной строке. Счётчики `i`, `j` живут только внутри своих циклов.

## 5. Одномерные и двумерные массивы
**Коротко:** массив — упорядоченный набор элементов одного типа фиксированной длины, индексы с 0. Массив — ссылочный тип. Двумерный массив — это массив массивов.

**Подробнее:**
- Декларация: `int[] a;` (только ссылка, массива ещё нет, `null`).
- Создание: `a = new int[5];` — элементы по умолчанию равны 0 (для boolean — false, для ссылок — null). Или сразу `int[] a = {1, 2, 3};`.
- Доступ: `a[0]`, длина `a.length` (это поле, без скобок). Выход за границы даёт `ArrayIndexOutOfBoundsException`.
- Двумерный: `double[][] m = new double[7][19];`. `m.length` = 7 (строки), `m[i].length` = 19. Строки могут быть разной длины («рваный» массив): `new int[3][]`.
- `new` выделяет память и возвращает ссылку.
- Полезный класс `java.util.Arrays`: `toString`, `sort`, `fill`, `copyOf`.

💡 `double[][] n = new double[7][19];`, элемент `n[i][j]`, обход двойным `for`.

## 6. Инструкции ветвления (if-else, switch) и циклов (do, while, for)
**Коротко:** `if/else` выбирает ветку по логическому условию, `switch` сравнивает значение с набором констант. Циклы: `while` (проверка до тела), `do-while` (тело хотя бы раз, проверка после), `for` (инициализация; условие; шаг), for-each (`for (double v : arr)`).

**Подробнее:**
- Условие в `if` обязательно типа `boolean` (в отличие от C, `if (1)` нельзя).
- `switch` работает с int, char, short, byte (и их обёртками), `String` и `enum`, **не с long/double/boolean**. Без `break` выполнение «проваливается» в следующий `case`. `default` срабатывает, если ничего не совпало. С Java 14 есть стрелочный `case 1 -> ...` без проваливания.
- Тернарный оператор: `условие ? a : b`.
- `break` — выйти из цикла, `continue` — перейти к следующей итерации, `break метка;` — выйти из вложенных циклов.

💡 Использую `if / else if / else`, потому что `l[i]` типа `long`, а `switch` с long не работает. Матрицу обхожу двумя вложенными `for`.

## 7. Операторы и выражения. Особенности вычисления, приоритеты
**Коротко:** выражение — комбинация операндов и операторов, дающая значение. Порядок вычисления определяют приоритеты. Операторы одного приоритета выполняются слева направо, кроме присваиваний (они справа налево).

**Подробнее — приоритеты от высшего к низшему:**
1. `()` `[]` `.`
2. унарные `++ -- + - ! ~`, приведение `(тип)`
3. `* / %`
4. `+ -`
5. сдвиги `<< >> >>>`
6. `< > <= >= instanceof`
7. `== !=`
8. `&` → `^` → `|`
9. `&&` → `||`
10. `?:`
11. `= += -= *= ...`

**Особенности:**
- Целочисленное деление: `7 / 2 == 3`; `%` — остаток.
- Переполнение int/long не вызывает ошибку, значение «заворачивается»: `(byte)(127 + 1) == -128`.
- Деление на 0: для целых — `ArithmeticException`, для double — `Infinity` или `NaN`.
- `&&` и `||` ленивые: второй операнд не вычисляется, если результат уже ясен.
- `i++` возвращает старое значение, `++i` — новое.
- Сравнение `double` через `==` ненадёжно из-за погрешности (`0.1 + 0.2 != 0.3`). `NaN != NaN`.

💡 `Math.pow(x,3) / (Math.cos(x) - 1)` — скобки обязательны, иначе деление выполнилось бы раньше вычитания. `/ 3 / 4` = `(… / 3) / 4`.

## 8. Математические функции. Класс `java.lang.Math`
**Коротко:** `Math` — класс стандартной библиотеки со **статическими** методами для математики. Он в пакете `java.lang`, который подключается автоматически, поэтому `import` не нужен.

**Подробнее:**
- Степени и корни: `pow`, `sqrt`, `cbrt`, `exp`, `log`, `log10`.
- Тригонометрия (в радианах): `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `atan2`, `toRadians`, `toDegrees`.
- Округление: `round` (до ближайшего, возвращает long), `floor` (вниз), `ceil` (вверх), `abs`, `max`, `min`.
- `random()` — double в [0; 1).
- Константы: `Math.PI`, `Math.E`.
- Можно `import static java.lang.Math.*;` и писать просто `sin(x)`.
- Методы static, потому что им не нужно состояние объекта: `new Math()` создать нельзя, конструктор приватный.

💡 Использую `pow`, `cos`, `asin`, `sin`, `exp`, `cbrt`, `random`. `cbrt` вместо `pow(a, 1.0/3)`: у pow с отрицательным основанием и дробной степенью получается NaN.

## 9. Подпрограммы, методы, параметры и возвращаемые значения
**Коротко:** метод — именованный блок кода внутри класса, который принимает параметры и может вернуть значение через `return`. Если метод ничего не возвращает, его тип `void`.

**Подробнее:**
- Сигнатура: `модификаторы тип_результата имя(параметры)`, например `public static double calculateElement(long li, double x)`.
- `static` — метод класса, вызывается без объекта: `Main.calculateElement(...)` или просто `calculateElement(...)` внутри того же класса.
- **В Java параметры передаются только по значению.** Для примитивов копируется само значение, и изменение внутри метода не видно снаружи. Для объектов и массивов копируется **ссылка**: внутри метода можно менять содержимое массива, но нельзя «подменить» сам массив снаружи.
- **Перегрузка**: несколько методов с одним именем, но разными параметрами.
- Переменное число аргументов: `static int sum(int... nums)`, внутри это массив.
- `main(String[] args)` — точка входа, `args` — аргументы командной строки.

💡 Три метода: `main`, `calculateElement` (вычисляет один элемент, возвращает double) и `printMatrix` (печатает, void). В `printMatrix` передаётся ссылка на массив `n`, копия всей матрицы не создаётся.

## 10. Форматированный вывод числовых данных
**Коротко:** `System.out.printf(формат, аргументы...)` (или `String.format`) подставляет значения по спецификаторам `%`.

**Подробнее:** шаблон `%[флаги][ширина][.точность]тип`
- типы: `d` — целое, `f` — вещественное, `e` — экспоненциальная запись, `s` — строка, `c` — символ, `%n` — перенос строки, `%%` — знак процента;
- `%.3f` — 3 знака после точки (с округлением);
- `%12.3f` — ширина 12, выравнивание вправо; `%-12.3f` — влево; `%012.3f` — дополнить нулями; `%+.3f` — всегда со знаком;
- разделитель дроби зависит от **локали**: в русской — запятая, в английской — точка. Задать явно: `System.out.printf(Locale.US, "%.3f", x)`;
- `print` — без переноса, `println` — с переносом строки.

💡 `System.out.printf("%12.3f ", matrix[i][j]);` — у каждого числа ровно 3 знака после запятой, ширина 12 выравнивает столбцы, пробел не даёт огромным числам слипаться. `Infinity`/`NaN` printf печатает словами.

## Вопросы-ловушки (из конспекта и на всякий случай)
- *Почему `byte a = 1, b = 2; byte c = a + b;` не компилируется?* При сложении byte становятся int, а присвоить int в byte без явного приведения нельзя.
- *Почему инкремент 127 в byte даёт −128?* Переполнение: в 8 битах после 01111111 идёт 10000000, а это −128 в дополнительном коде.
- *Сколько элементов может хранить массив?* До `Integer.MAX_VALUE` (≈2³¹−1), потому что индекс — int. На практике меньше: ограничивает память JVM.
- *Является ли `Float.NaN` числом?* Это значение типа float, «не число» по IEEE 754. `NaN == NaN` → false, проверять надо через `Double.isNaN(x)`.
- *Что делает `for(;;) {}`?* Бесконечный цикл.
- *Почему у тебя Infinity?* e^(eˣ) при x > ~6.57 выходит за максимум double (≈1.8·10³⁰⁸), это переполнение, а не ошибка.
