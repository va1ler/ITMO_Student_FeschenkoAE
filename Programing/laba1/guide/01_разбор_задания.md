# 01. Разбор задания (вариант 561306)

## Что делает программа, в одном абзаце
Создаём два одномерных массива: **l** из 7 целых чисел и **x** из 19 случайных дробных. Потом строим таблицу **n** из 7 строк и 19 столбцов. Каждая клетка `n[i][j]` считается по формуле. Какую формулу взять, решает число `l[i]` (номер строки), а в саму формулу подставляется `x[j]` (номер столбца). В конце печатаем таблицу, у каждого числа 3 знака после запятой.

```
            x[0]   x[1]   x[2]  ...  x[18]     ← 19 столбцов (случайные числа)
l[0] = 16 | n00    n01    n02   ...  n0,18     ← формула «Б»
l[1] = 14 | ...                                ← формула «В»
l[2] = 12 | ...                                ← формула «Б»
l[3] = 10 | ...                                ← формула «А»
l[4] =  8 | ...                                ← формула «Б»
l[5] =  6 | ...                                ← формула «В»
l[6] =  4 | ...                                ← формула «В»
```

## Пункт 1. Массив `l` (тип `long`)
«Чётные числа от 4 до 16 включительно в порядке убывания» → **16, 14, 12, 10, 8, 6, 4**. Это 7 штук, поэтому в таблице 7 строк.

Закономерность: `l[i] = 16 - 2*i` (i = 0 → 16, i = 1 → 14, …, i = 6 → 4).

## Пункт 2. Массив `x` (тип `double`)
Нужно 19 случайных чисел от −2.0 до 13.0.

`Math.random()` выдаёт случайное число в диапазоне [0; 1). Чтобы получить [−2; 13):
- ширина нужного диапазона 13 − (−2) = **15**, поэтому умножаем на 15 и получаем [0; 15);
- потом сдвигаем на −2 и получаем [−2; 13).

Итого `x[i] = Math.random() * 15.0 - 2.0`.

## Пункт 3. Три формулы

| Когда | Формула на бумаге | Как записать в Java |
|---|---|---|
| **А:** `l[i] == 10` | ( ((x³ / (cos x − 1))² / 3) / 4 ) ^ arcsin(sin x) | `Math.pow( Math.pow(Math.pow(x,3) / (Math.cos(x) - 1), 2) / 3 / 4 , Math.asin(Math.sin(x)) )` |
| **Б:** `l[i]` ∈ {8, 12, 16} | ∛( e^(eˣ) ) | `Math.cbrt( Math.exp( Math.exp(x) ) )` |
| **В:** все остальные (14, 6, 4) | ∛( cos( ( ((x − 3/4) / 2) / 3 )² ) ) | `Math.cbrt( Math.cos( Math.pow( (x - 3.0/4) / 2 / 3, 2) ) )` |

Формулу собирают **изнутри наружу**. Например, «Б»: сначала `Math.exp(x)`, это eˣ. Потом `Math.exp(...)` от этого, это e^(eˣ). В конце `Math.cbrt(...)`, кубический корень.

## Подводные камни (про них любят спрашивать на защите)

1. **`3/4` в Java равно 0, а не 0.75.** Если оба числа целые, деление тоже целое, и дробная часть отбрасывается. Поэтому пишем `3.0/4` или `0.75`.
2. **Корень третьей степени: `Math.cbrt`, а не `Math.pow(a, 1.0/3)`.** `pow` с отрицательным основанием и дробной степенью возвращает **NaN**. Например, `Math.pow(-8, 1.0/3)` = NaN, а `Math.cbrt(-8)` = −2. В формуле «В» косинус бывает отрицательным, так что это важно.
3. **Infinity в строках 16, 12, 8 — это нормально.** Там e^(eˣ), а x доходит до 13. e¹³ ≈ 442 000, и e в такой степени — число с ~192 000 цифр. В `double` оно не влезает, поэтому получается `Infinity`. Так и должно быть, это математика, а не ошибка программы. (В задании написано: «если получается NaN — возможно так и должно быть». С Infinity то же самое.)
4. **Огромные числа в строке 10.** Основание там может быть порядка 10⁵, степень до ±1.57, так что встречаются числа вроде 188675915875.844. Это тоже нормально.
5. **`l[i] == 10`, а не `l[i] = 10`.** Одно `=` означает присваивание, два `==` означают сравнение.
6. **Сравнивать с числом можно**, потому что `l[i]` имеет тип `long`, а 10 — `int`. Java сама расширит `int` до `long`. Это пример автоматического преобразования типов.

## Пункт 4. Вывод
`System.out.printf("%12.3f ", n[i][j]);` означает: вещественное число (`f`), 3 знака после точки (`.3`), не меньше 12 символов ширины (`12`, чтобы столбцы стояли ровно), в конце пробел, чтобы огромные числа не слипались. После каждой строки нужен `System.out.println();`, это перенос строки.

На маке с русской локалью числа печатаются с **запятой** (`0,743`), а на helios с **точкой** (`0.743`). Это не ошибка, `printf` просто берёт разделитель из настроек системы.
