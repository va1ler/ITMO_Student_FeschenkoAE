## 📊 Как набрать баллы (1 семестр)

| Что | Сколько | Баллы |
|---|---|---|
| Очные практики (по четвергам) | 8 × 5 | **40** |
| Посещение лекций | 8 × 1 | **8** |
| Дистанционные практики (по субботам, заочно) | 7 × 4 | **28** |
| **Всего можно набрать** | | **76** |
| Проекты / НИР | — | только во 2 семестре |

- **Зачёт = 60+ баллов.** Если набрал, зачёт ставится автоматом.
- **Меньше 60 →** зачётный тест с прокторингом, до **24 баллов**; за нарушения результат аннулируется. Не хватило и после теста — допсессия.
- Запас небольшой: из 76 можно потерять только **16**. Пропуск очной практики стоит 5 баллов, дистанционной — 4.
- Баллы ведутся в Excel-таблице курса. Колонки в БАРС не совпадают со структурой курса, поэтому сверяй только **общую сумму**.
