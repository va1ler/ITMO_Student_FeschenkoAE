## Task1 (вар. 4): время → `(TBD)`

**Условие.** Время — строка `HH:MM:SS` или `HH:MM`, где `HH` от 00 до 23, `MM` и `SS` от 00 до 59. Заменить каждое вхождение на `(TBD)`.

Пример:
```
Ввод:  Уважаемые студенты! В эту субботу в 15:00 планируется доп. занятие на 2 часа. То есть в 17:00:01 оно уже точно кончится.
Вывод: Уважаемые студенты! В эту субботу в (TBD) планируется доп. занятие на 2 часа. То есть в (TBD) оно уже точно кончится.
```

**Шаги.**
1. Шаблон для часов 00–23 (ровно две цифры). Теория §4.
2. Шаблон для минут/секунд 00–59.
3. Собери: часы, двоеточие, минуты, **необязательная** группа «двоеточие + секунды». §6.
4. Ограничь края, чтобы `123:45` или `12:345` не считались временем. Сначала через `\b` (§5), потом подумай про lookaround (§7).
5. Функция `solve(text)` с одним `re.sub`. Потом тесты (§10).

<details><summary>Подсказка 1: часы</summary>

Две ветки: первая цифра 0 или 1 и любая вторая, **или** 2 и вторая от 0 до 3. Не забудь `(?:...)` вокруг, иначе `|` разрежет весь шаблон пополам.
</details>

<details><summary>Подсказка 2: секунды необязательны</summary>

`(?:...)?` вокруг «двоеточие + минутный шаблон».
</details>

<details><summary>Подсказка 3: почему одного \b мало</summary>

На `17:00:61` шаблон с `\b` заменит `17:00`, и получится `(TBD):61`. Сделай проверку: перед временем нет цифры и нет «цифра:», после нет цифры и нет «:цифра». Каркас: `(?<!\d)(?<!\d:)` … `(?!:?\d)`.
</details>

**Идеи для тестов** (ответы посчитай сам): пример из задания; `00:00` и `23:59:59`; `24:00`, `12:60`, `9:30` (одна цифра в часах, по условию не время); `17:00:61`; время в конце предложения `в 15:00.`; текст без времени.

## Task2 (вар. 1): слова ровно с одной гласной

**Условие.** Найти слова, в которых встречается **строго одна** гласная буква (она может повторяться: окно, трава, молоко). Отсортировать сначала по длине, потом лексикографически.

Пример:
```
Ввод:  Классное слово – обороноспособность, которое должно идти после слов: трава и молоко.
Вывод: и, идти, слов, слово, трава, должно, молоко, обороноспособность (каждое с новой строки)
```

**Шаги.**
1. Строка гласных: `аеёиоуыэюя` (с `ё`! теория §3). Регистр — флаг `re.I`.
2. Класс «согласная» = символ слова, который не гласная: `[^\W…гласные…]` (§3).
3. Идея шаблона для слова: граница → согласные (0 или больше) → **одна гласная в группе** → дальше только согласные **или та же гласная** `\1` → граница (§6).
4. Собирай слова через `finditer` + `m.group()`, **не** через `findall` (§8, подвох с группами).
5. `sorted(..., key=lambda w: (len(w), w))`. Решить про регистр и повторы слов, сказать на защите.
6. Тесты.

<details><summary>Подсказка 1: каркас шаблона</summary>

```
\b  [согласные]*  ([гласные])  (?:[согласные]|\1)*  \b
```
Пробелы тут только для читаемости. Строку гласных удобно держать в переменной и подставлять через `rf'...'`.
</details>

<details><summary>Подсказка 2: почему не находится «Окно»</summary>

Без `re.I` первая гласная `О` (заглавная) не входит в класс из строчных букв. С `re.I` и класс, и `\1` становятся нечувствительны к регистру.
</details>

**Вопросы, которые стоит решить и уметь объяснить:**
- Слова без гласных (`в`, `к`) — не подходят: нужна ровно одна гласная.
- `ь` и `ъ` — не гласные, слово «съел» подходит (одна `е`).
- Повторяющиеся слова оставлять или убирать? В примере повторов нет. Выбери и скажи, почему.
- Сортировка с заглавными: `'Окно' < 'дом'` в Python, потому что заглавные идут раньше. Можно сортировать по `w.lower()`.

**Идеи для тестов:** пример из задания; слова с `ё` (`ёлка` не подходит: ё и а; `мёд` подходит); заглавные (`ОКНО`, `Трава`); слово с цифрой или дефисом (`кто-то` — `\w` не включает дефис, это два слова); текст без подходящих слов.

## Task3 (вар. 0, доп. +20): проверка cron-выражения

**Условие.** Пять полей через пробел: минуты 0–59, часы 0–23, дни месяца 1–31, месяцы 1–12, дни недели 0–6. В полях допустимы `*`, `-`, `/`, `,` и цифры. Названия (`JAN`, `MON`) не нужны. Циклов и `if` минимум.

Примеры корректных: `30 14 * * *`, `*/5 * * * *`, `0 0 1 1 *`.

**Шаги.**
1. Шаблоны чисел для каждого поля (как в Task1, §4). Подумай, разрешать ли ведущий ноль (`05`).
2. **Элемент** поля: `*` или `число`, или `число-число`, после чего необязательно `/шаг`.
3. **Поле** = элемент, затем 0 или больше раз «запятая + элемент».
4. Функция `field(num)`, которая по шаблону числа строит шаблон поля. Пять раз её вызываешь и склеиваешь через пробел. §8, сборка из кусков.
5. Проверка: `re.fullmatch` → «OK» или «Ошибка».
6. Тесты: и правильные, и неправильные.

<details><summary>Подсказка 1: элемент поля</summary>

```
(?:\*|ЧИСЛО(?:-ЧИСЛО)?)(?:/ШАГ)?
```
Шаг — положительное число: `[1-9]\d*` (`*/0` — ошибка).
</details>

<details><summary>Подсказка 2: числа</summary>

- минуты: `[0-5]?\d`
- часы: как в Task1, только первая цифра необязательна;
- дни месяца: `1–9`, `10–29`, `30–31` — три ветки;
- месяцы: `1–9` или `10–12`;
- дни недели: одна цифра 0–6.
</details>

**Что регулярка не проверит** (сказать на защите): что в диапазоне `5-3` начало меньше конца, что 31 февраля не бывает. Это логика, а не формат.

**Идеи для тестов:** три примера из задания; сложное корректное `0,15,30,45 9-17 * 1-6/2 1-5`; `60 * * * *`; `* 24 * * *`; `* * 0 * *`; `* * * 13 *`; `* * * * 7`; `*/0 * * * *`; четыре поля вместо пяти; `1--2 * * * *`.

**Можно лучше (не обязательно):** сообщать, какое именно поле неверное. Разбить по пробелам и проверить каждое поле своим шаблоном.
