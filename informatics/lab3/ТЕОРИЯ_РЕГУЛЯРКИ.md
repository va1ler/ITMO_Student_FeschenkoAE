## §1. Что такое регулярное выражение

**Регулярное выражение (регулярка, regex)** — это шаблон, описывающий множество строк. Программа-движок ищет в тексте подстроки, подходящие под шаблон.

Зачем: найти, проверить, заменить или разрезать текст по правилу, которое трудно описать через `if` и циклы. Например, «все email в тексте» или «все времена вида ЧЧ:ММ».

В Python регулярки — это встроенный модуль `re`:
```python
import re
re.findall(r'\d+', 'в 2026 году 12 месяцев')   # ['2026', '12']
```

**Почему `r'...'`.** Буква `r` делает строку «сырой»: обратный слэш в ней не обрабатывается Python. Без неё `'\b'` — это символ backspace, а не граница слова. **Всегда пиши шаблоны как `r'...'`.**

Откуда термин: регулярные выражения пришли из теории формальных языков (Клини, 1950-е). Регулярный язык — то, что распознаёт конечный автомат. В Unix их ввёл Кен Томпсон (редактор `ed`, потом `grep`).

<details><summary>Упражнения §1</summary>

1. Что вернёт `re.findall(r'\d+', 'a1b22c333')`?
2. Почему `'\n'` и `r'\n'` — разные строки? Какая у каждой длина?

<details><summary>Ответы</summary>

1. `['1', '22', '333']`.
2. `'\n'` — один символ «перевод строки», длина 1. `r'\n'` — два символа `\` и `n`, длина 2. Модуль `re` сам поймёт `\n` в шаблоне как перевод строки.
</details>
</details>

## §2. Обычные символы и метасимволы

Большинство символов означают сами себя: шаблон `кот` находит подстроку «кот».

**Метасимволы** имеют особый смысл: `. ^ $ * + ? { } [ ] \ | ( )`.
Чтобы найти сам символ, его **экранируют** обратным слэшем: `\.` — точка, `\(` — скобка, `\\` — слэш.

| Шаблон | Значение |
|---|---|
| `.` | любой символ, кроме `\n` |
| `\.` | именно точка |
| `a\+b` | строка «a+b» |

<details><summary>Упражнения §2</summary>

1. Шаблон для строки `3.14` (именно с точкой).
2. Что найдёт `a.c` в тексте `abc a.c a-c ac`?

<details><summary>Ответы</summary>

1. `r'3\.14'`. Без слэша `3.14` найдёт и «3914».
2. `abc`, `a.c`, `a-c`. Не найдёт `ac`, потому что точка требует ровно один символ.
</details>
</details>

## §3. Классы символов

`[...]` — **один** символ из перечисленных.

| Шаблон | Значение |
|---|---|
| `[абв]` | а, б или в |
| `[0-9]` | цифра (диапазон) |
| `[а-яА-Я]` | русская буква… **кроме ё и Ё!** |
| `[^0-9]` | любой символ, **кроме** цифры (`^` в начале скобок — отрицание) |
| `[.]` | внутри скобок точка — просто точка |

**Готовые классы:**

| | Значение | Противоположный |
|---|---|---|
| `\d` | цифра | `\D` |
| `\w` | «символ слова»: буква (в Python 3 **и русская**), цифра, `_` | `\W` |
| `\s` | пробельный: пробел, `\t`, `\n` | `\S` |

⚠️ **Ловушка с ё.** В Unicode буква `ё` стоит отдельно от `а-я`, поэтому `[а-я]` её не ловит. Пиши гласные явно: `[аеёиоуыэюя]`.

**Приём «буква, но не гласная».** Внутри `[^...]` можно писать готовые классы: `[^\Wаеёиоуыэюя]` — «не (не-буква-слова) и не гласная», то есть символ слова, который не гласная. Это согласная (плюс цифры, `_`, `ь`, `ъ`). Пригодится в Task2.

<details><summary>Упражнения §3</summary>

1. Шаблон для одной шестнадцатеричной цифры.
2. Что найдёт `re.findall(r'[аеёиоуыэюя]', 'ёлка')`? А `[а-я]` в слове «ёж»?
3. Шаблон для одного символа, который не пробел и не запятая.

<details><summary>Ответы</summary>

1. `r'[0-9a-fA-F]'`.
2. `['ё', 'а']`. `[а-я]` найдёт только `ж`.
3. `r'[^ ,]'`.
</details>
</details>

## §4. Квантификаторы (сколько раз)

Ставятся **после** символа, класса или группы.

| | Сколько раз |
|---|---|
| `*` | 0 и больше |
| `+` | 1 и больше |
| `?` | 0 или 1 (необязательный) |
| `{3}` | ровно 3 |
| `{2,4}` | от 2 до 4 |
| `{2,}` | 2 и больше |

**Жадность.** По умолчанию квантификаторы **жадные**: берут как можно больше, потом при необходимости отдают. Если добавить `?` (`*?`, `+?`), они станут **ленивыми** и возьмут как можно меньше.
```python
re.findall(r'<.+>',  '<b>жир</b>')   # ['<b>жир</b>']  — жадный
re.findall(r'<.+?>', '<b>жир</b>')   # ['<b>', '</b>'] — ленивый
```

**Числа из диапазона регулярка «не понимает»**: она работает с символами, а не с числами. Число 0–23 — это «0 или 1 и любая цифра» **или** «2 и цифра 0–3»: `[01]\d|2[0-3]`. Это главный приём Task1 и Task3.

<details><summary>Упражнения §4</summary>

1. Шаблон для минут `00`–`59` (ровно две цифры).
2. Шаблон для числа 1–12 без ведущего нуля.
3. Шаблон для числа 0–59, где ведущий ноль необязателен (`5` и `05` оба подходят).
4. Что вернёт `re.findall(r'\d{2,3}', '12345')`?

<details><summary>Ответы</summary>

1. `r'[0-5]\d'`.
2. `r'[1-9]|1[0-2]'`. Внутри большего шаблона оберни в группу: `(?:[1-9]|1[0-2])`.
3. `r'[0-5]?\d'`.
4. `['123', '45']`: жадно берёт 3 цифры, потом ещё 2.
</details>
</details>

## §5. Якоря (где в строке)

Якоря не «съедают» символы, они проверяют позицию.

| | Позиция |
|---|---|
| `^` | начало строки |
| `$` | конец строки |
| `\b` | граница слова: с одной стороны `\w`, с другой — не `\w` (или край строки) |
| `\B` | не граница слова |

```python
re.findall(r'\bкот\b', 'кот котлета скот кот.')   # ['кот', 'кот']
```

⚠️ `\b` считает словом `\w`, а двоеточие и точка — не `\w`. Поэтому в `17:00:61` между `00` и `:` **есть** граница. Для Task1 это важно (см. §7).

<details><summary>Упражнения §5</summary>

1. Шаблон, проверяющий, что вся строка состоит из цифр.
2. Сколько совпадений у `\b\d\d\b` в тексте `12 345 67`?

<details><summary>Ответы</summary>

1. `r'^\d+$'` (или `re.fullmatch(r'\d+', s)`, см. §8).
2. Два: `12` и `67`. В `345` нет границы между 4 и 5.
</details>
</details>

## §6. Группы, альтернация, обратные ссылки

**Альтернация** `|` — «или». У неё самый низкий приоритет: `кот|пёс ы` значит `кот` **или** `пёс ы`. Поэтому её почти всегда оборачивают в группу.

**Группы:**

| | Что делает |
|---|---|
| `(...)` | группирует **и запоминает** (захватывающая группа, номер 1, 2, …) |
| `(?:...)` | только группирует, не запоминает |
| `(?P<имя>...)` | захватывающая группа с именем |

```python
m = re.search(r'(\d\d):(\d\d)', 'в 15:30')
m.group(0)  # '15:30' — всё совпадение
m.group(1)  # '15'
m.group(2)  # '30'
```

Квантификатор после группы применяется к ней целиком: `(?::\d\d)?` — «необязательно: двоеточие и две цифры». Это секунды в Task1.

**Обратная ссылка** `\1` — «ровно тот же текст, что захватила группа 1».
```python
re.findall(r'\b(\w+)\s+\1\b', 'ошибка ошибка тут тут')   # ['ошибка', 'тут']
```
Это ключ к **Task2**: захватить первую встреченную гласную в группу, а дальше разрешать только согласные **или `\1`**, то есть эту же гласную.

<details><summary>Упражнения §6</summary>

1. Шаблон для «кот» или «пёс» как целых слов.
2. Шаблон для слов, которые начинаются и заканчиваются одной и той же буквой (`шалаш`, `ага`).
3. Шаблон для слова, в котором есть две **одинаковые** буквы подряд (`класс`, `ванна`).

<details><summary>Ответы</summary>

1. `r'\b(?:кот|пёс)\b'`.
2. `r'\b(\w)\w*\1\b'`. Заметь: однобуквенное слово сюда не попадёт, потому что `\1` требует ещё одну букву. Для `findall` здесь вернётся только группа — см. §8.
3. `r'\b\w*(\w)\1\w*\b'`.
</details>
</details>

## §7. Просмотр вперёд и назад (lookaround)

Проверяет, что **рядом** есть или нет шаблона, но сам его не захватывает.

| | Значение |
|---|---|
| `X(?=Y)` | X, если **после** него идёт Y |
| `X(?!Y)` | X, если после него **не** идёт Y |
| `(?<=Y)X` | X, если **перед** ним Y |
| `(?<!Y)X` | X, если перед ним **не** Y |

В Python шаблон внутри `(?<=...)` и `(?<!...)` должен иметь **фиксированную длину**: `(?<!\d)` можно, `(?<!\d+)` нельзя.

Зачем это Task1: `\b` не спасёт от `17:00:61` (заменится `17:00`, а `:61` останется) или от `10:00:00:00`. Если сказать «перед временем нет цифры или `цифра:`, после нет цифры или `:цифра`», такие строки не тронутся. Это не обязательно, но на защите это хороший плюс и отличный тест.

<details><summary>Упражнения §7</summary>

1. Найди числа, после которых идёт `₽`, но без самого знака.
2. Найди слова «кот», перед которыми нет слова «не » (с пробелом).

<details><summary>Ответы</summary>

1. `r'\d+(?=₽)'`.
2. `r'(?<!не )\bкот\b'`.
</details>
</details>

## §8. Функции модуля `re`

| Функция | Что делает | Возвращает |
|---|---|---|
| `re.search(p, s)` | первое совпадение **где угодно** | `Match` или `None` |
| `re.match(p, s)` | совпадение **с начала** строки | `Match` или `None` |
| `re.fullmatch(p, s)` | **вся** строка подходит | `Match` или `None` |
| `re.findall(p, s)` | все совпадения | список строк (подвох ниже) |
| `re.finditer(p, s)` | все совпадения | итератор объектов `Match` |
| `re.sub(p, repl, s)` | заменить все совпадения на `repl` | новая строка |
| `re.split(p, s)` | разрезать строку по шаблону | список |
| `re.compile(p, flags)` | «скомпилировать» шаблон один раз | объект шаблона с теми же методами |

⚠️ **Подвох `findall`.** Если в шаблоне есть захватывающие группы, `findall` возвращает **содержимое групп**, а не всё совпадение. В Task2 у тебя будет группа для `\1`, поэтому бери `finditer` и `m.group()` (или `m.group(0)`).

**`re.sub` с функцией.** Вместо строки можно передать функцию, которая получает `Match` и возвращает замену. Тебе это не нужно (у тебя замена всегда `(TBD)`), но про это любят спросить.

**Флаги:**
- `re.IGNORECASE` (`re.I`) — без учёта регистра. Обратные ссылки тоже становятся нечувствительны к регистру: `(о)…\1` поймает и «О».
- `re.MULTILINE` (`re.M`) — `^` и `$` работают на каждой строке текста.
- `re.VERBOSE` (`re.X`) — в шаблоне можно ставить пробелы и комментарии `#`. Удобно для длинного cron-шаблона.

**Сборка шаблона из кусков** (для Task3). Шаблон — обычная строка, его можно собрать f-строкой:
```python
HOUR = r'(?:[01]?\d|2[0-3])'
pattern = rf'^{HOUR}:{HOUR}$'   # rf — сырая f-строка
```
⚠️ В f-строке фигурные скобки квантификатора надо удваивать: `{{2}}`. Проще вообще не писать `{n}` в f-строках.

**Сортировка по двум признакам** (для Task2): `sorted(words, key=lambda w: (len(w), w))` — сначала по длине, при равной длине по алфавиту. Заглавные буквы в Python идут **раньше** строчных, а `ё` — **после** `я`. Подумай, нужно ли приводить к нижнему регистру, и скажи на защите, что решил.

<details><summary>Упражнения §8</summary>

2. Замени все числа в строке на `#`.

<details><summary>Ответы</summary>

2. `re.sub(r'\d+', '#', s)`.
3. `re.fullmatch(r'P\d{4}', s)` — вернёт `Match` или `None`, значит, в `if` его можно ставить напрямую.
4. `['a', 'c', 'ab', 'bb']`.
</details>
</details>

## §9. Как это работает внутри (для защиты)

- Регулярное выражение можно превратить в **конечный автомат**: состояния + переходы по символам. Строка подходит, если автомат дошёл до принимающего состояния.
- Движок Python (как и в Java, Perl, JS) — **с возвратами (backtracking)**. Он пробует варианты по очереди и откатывается, если не вышло. Именно поэтому работают обратные ссылки и lookaround: с «чистым» автоматом их не сделать, и строго говоря это уже не «регулярные» языки.
- Цена возвратов: плохой шаблон вроде `(a+)+$` на строке `aaaa…ab` работает экспоненциально долго (**катастрофический бэктрекинг**, на этом построены ReDoS-атаки).
- `re.compile` один раз разбирает шаблон, и дальше его можно применять много раз. `re.sub` и другие функции внутри тоже кешируют шаблоны, так что выигрыш небольшой, но код читается лучше.

## §10. Тесты

По заданию на каждую задачу нужно **минимум 5 тестов**, ответ к каждому ты находишь **сам, без регулярок**, а программа сравнивает его со своим.

Удобная форма:
```python
tests = [
    ('входной текст 1', 'ожидаемый ответ 1'),
    ('входной текст 2', 'ожидаемый ответ 2'),
]
for text, expected in tests:
    got = solve(text)
    print('OK  ' if got == expected else 'FAIL', repr(got))
```
Хорошие тесты покрывают:
1. **пример из задания** (обязательно);
2. **обычный случай** из жизни;
3. **границы** (`00:00`, `23:59:59`, однобуквенное слово, `59` в минутах);
4. **почти правильное**, что не должно сработать (`24:00`, `12:60`, `ёлка`, `60 * * * *`);
5. **пустой ввод** или текст без совпадений.
