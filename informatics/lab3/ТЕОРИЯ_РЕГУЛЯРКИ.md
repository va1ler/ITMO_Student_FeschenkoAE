## §1. Что такое регулярное выражение

**Регулярное выражение (регулярка, regex)** — шаблон, который описывает множество строк. Программа ищет в тексте куски, подходящие под шаблон.

Зачем: найти, проверить или заменить текст по правилу, которое сложно описать через `if` и циклы. Например, «все времена вида ЧЧ:ММ».

В Python для этого встроенный модуль `re`:
```python
import re
print(re.findall(r'\d+', 'в 2026 году 12 месяцев'))   # ['2026', '12']
```
`re.findall(шаблон, текст)` возвращает список всех найденных кусков. **Текст передаётся вторым аргументом всегда**, без него Python выдаст ошибку.

**Зачем `r` перед шаблоном.** В обычной строке Python сам обрабатывает обратный слэш: `'\n'` превращается в один символ «перевод строки». Буква `r` делает строку «сырой»: слэш остаётся слэшем. Регулярки сплошь состоят из слэшей (`\d`, `\b`), и без `r` Python испортит их раньше, чем строку увидит `re`. **Шаблоны всегда пиши как `r'...'`.**

Откуда термин: из теории формальных языков (Клини, 1950-е). В программы регулярки принёс Кен Томпсон (редактор `ed`, потом `grep` в Unix).

**Упр. 1.1.** Найди все числа (одна или больше цифр подряд).
Должно вывести: `['1', '22', '333']`
```python
print(re.findall(r'???', 'a1b22c333'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'\d+', 'a1b22c333'))
```
`\d` — цифра, `+` — «одна или больше». Подробно будет в §4 и §6, тут просто убедись, что всё запускается.
</details>

**Вопрос 1.2.** Что выведет `print(len('\n'), len(r'\n'))` и почему?
<details><summary>Ответ</summary>

`1 2`. В обычной строке Python превращает `\n` в один символ (перевод строки). В сырой строке `r'\n'` это два символа: `\` и `n`. **Регулярки тут ни при чём**, это свойство строк Python.
</details>

## §2. Функции модуля `re`

| Функция | Что делает | Что возвращает |
|---|---|---|
| `re.findall(p, s)` | ищет все совпадения | список строк |
| `re.finditer(p, s)` | ищет все совпадения | объекты `Match`, у каждого `.group()` — найденный текст |
| `re.search(p, s)` | ищет **первое** совпадение где угодно | `Match` или `None` |
| `re.fullmatch(p, s)` | проверяет, что **вся** строка подходит | `Match` или `None` |
| `re.sub(p, repl, s)` | заменяет все совпадения на `repl` | новую строку |

`None` значит «не нашлось». Поэтому проверка «подходит ли строка» пишется как `re.fullmatch(p, s) is not None`, а в `if` можно писать просто `if re.fullmatch(p, s):`.

Шаблон в упражнениях этого раздела всегда `\d+` (число). Здесь тренируем **функции**, а не шаблоны.

**Упр. 2.1.** Найди первое число в тексте.
Должно вывести: `'12'`
```python
print(re.search(r'???', 'дом 12, кв. 5').group())
```
<details><summary>Ответ</summary>

```python
print(re.search(r'\d+', 'дом 12, кв. 5').group())
```
`search` останавливается на первом совпадении, `.group()` достаёт его текст.
</details>

**Упр. 2.2.** Проверь, что строка **целиком** — число.
Должно вывести: `True`
```python
print(re.fullmatch(r'???', '2026') is not None)
```
<details><summary>Ответ</summary>

```python
print(re.fullmatch(r'\d+', '2026') is not None)
```
Поменяй текст на `'20a6'`: выведет `False`, потому что буква `a` не цифра.
</details>

**Упр. 2.3.** Замени все числа на `#`.
Должно вывести: `'дом #, кв. #'`
```python
print(re.sub(r'???', '#', 'дом 12, кв. 5'))
```
<details><summary>Ответ</summary>

```python
print(re.sub(r'\d+', '#', 'дом 12, кв. 5'))
```
`sub` возвращает новую строку, исходная не меняется. Именно так будет устроен Task1.
</details>

**Упр. 2.4.** Чем отличаются `\d` и `\d+`?
Сначала **угадай** вывод, потом запусти:
```python
print(re.findall(r'\d', 'a1b22c333'))
```
<details><summary>Ответ</summary>

`['1', '2', '2', '3', '3', '3']`

Без `+` каждая цифра находится отдельно. С `+` — всё число целиком: `['1', '22', '333']`.
</details>

## §3. Обычные символы и экранирование

Большинство символов означают сами себя: шаблон `кот` находит «кот».

**Метасимволы** имеют особый смысл: `. ^ $ * + ? { } [ ] \ | ( )`. Чтобы найти сам символ, перед ним ставят обратный слэш: `\.` — точка, `\(` — скобка.

Точка без слэша `.` означает «**любой** один символ» (кроме перевода строки).

**Упр. 3.1.** Найди именно `3.14`, а не `3914`.
Должно вывести: `['3.14']`
```python
print(re.findall(r'???', '3.14 3914'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'3\.14', '3.14 3914'))
```
Без слэша `3.14` нашло бы и `3914`: точка — любой символ.
</details>

**Упр. 3.2.** Что найдёт `a.c`?
Сначала **угадай** вывод, потом запусти:
```python
print(re.findall(r'a.c', 'abc a.c a-c ac'))
```
<details><summary>Ответ</summary>

`['abc', 'a.c', 'a-c']`

Точка требует **ровно один** символ между `a` и `c`, поэтому `ac` не подходит.
</details>

**Упр. 3.3.** Найди номер пункта в скобках, например `(1)`.
Должно вывести: `['(1)']`
```python
print(re.findall(r'???', 'пункт (1) и пункт 2'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'\(\d\)', 'пункт (1) и пункт 2'))
```
Скобки — метасимволы, их экранируют: `\(` и `\)`.
</details>

## §4. Классы символов

`[...]` означает **один** символ из перечисленных. Без квадратных скобок это просто текст.

| Шаблон | Значение |
|---|---|
| `[абв]` | а, б или в |
| `[0-9]` | цифра (диапазон через дефис) |
| `[а-я]` | русская строчная буква, **кроме ё** |
| `[^0-9]` | любой символ, **кроме** цифры. `^` сразу после `[` — это «не» |

**Готовые классы:**

| | Значение | Противоположный |
|---|---|---|
| `\d` | цифра | `\D` |
| `\w` | буква (и русская тоже), цифра или `_` | `\W` |
| `\s` | пробел, табуляция, перевод строки | `\S` |

⚠️ **Буква ё** стоит в Unicode отдельно, поэтому `[а-я]` её не ловит. Гласные пиши списком: `[аеёиоуыэюя]`.

**Приём «согласная»** (нужен в Task2): `[^\Wаеёиоуыэюя]` читается как «не (не-буква) и не гласная», то есть буква, но не гласная.

Пока все шаблоны находят **по одному символу**. Как брать несколько подряд, будет в §6. В упражнении 4.3 `+` уже встречался в §1, он значит «один или больше».

**Упр. 4.1.** Найди все гласные.
Должно вывести: `['ё', 'а']`
```python
print(re.findall(r'???', 'ёлка'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'[аеёиоуыэюя]', 'ёлка'))
```
Гласные перечислены в квадратных скобках, `ё` входит в список.
</details>

**Упр. 4.2.** Что найдёт `[а-я]` в слове «ёж»?
Сначала **угадай** вывод, потом запусти:
```python
print(re.findall(r'[а-я]', 'ёж'))
```
<details><summary>Ответ</summary>

`['ж']`

`ё` не входит в диапазон `а-я`. Это частая ловушка.
</details>

**Упр. 4.3.** Разбей текст на слова: найди куски из символов, которые не пробел и не запятая.
Должно вывести: `['раз', 'два', 'три']`
```python
print(re.findall(r'???', 'раз, два три'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'[^ ,]+', 'раз, два три'))
```
`[^ ,]` — любой символ, кроме пробела и запятой. `+` — один или больше таких подряд.
</details>

**Упр. 4.4.** Найди все шестнадцатеричные цифры.
Должно вывести: `['1', 'F']`
```python
print(re.findall(r'???', 'x=1F'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'[0-9a-fA-F]', 'x=1F'))
```
Три диапазона в одних скобках. `x` не входит в `a-f`.
</details>

**Упр. 4.5.** Найди все согласные.
Должно вывести: `['к', 'н']`
```python
print(re.findall(r'???', 'окно'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'[^\Wаеёиоуыэюя]', 'окно'))
```
Приём из теории выше. Он пригодится в Task2.
</details>

## §5. «Или» и группировка

`|` означает «или»: `кот|пёс` найдёт и «кот», и «пёс».

⚠️ `|` делит **весь** шаблон пополам. `кот|пёсы` значит «`кот`» **или** «`пёсы`», а не «коты или пёсы». Чтобы «или» действовало только на часть шаблона, её берут в скобки `(?:...)`:
- `(?:кот|пёс)ы` — «коты» или «пёсы».

⚠️ **Порядок веток важен.** Движок пробует ветки слева направо и берёт **первую подошедшую**. Если короткая ветка стоит раньше длинной, длинная может не успеть сработать. Правило: **длинную ветку ставь первой.**

**Упр. 5.1.** Найди «кот» или «пёс».
Должно вывести: `['кот', 'пёс']`
```python
print(re.findall(r'???', 'кот и пёс'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'кот|пёс', 'кот и пёс'))
```
Самое простое «или».
</details>

**Упр. 5.2.** Найди «коты» и «пёсы», но не «псы».
Должно вывести: `['коты', 'пёсы']`
```python
print(re.findall(r'???', 'коты, псы, пёсы'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'(?:кот|пёс)ы', 'коты, псы, пёсы'))
```
Без скобок `кот|пёсы` нашло бы `['кот', 'пёсы']`: «или» разрезало бы шаблон.
</details>

**Упр. 5.3.** Что найдёт `1|12` в тексте `12`?
Сначала **угадай** вывод, потом запусти:
```python
print(re.findall(r'1|12', '12'))
```
<details><summary>Ответ</summary>

`['1']`

Первая ветка `1` подошла, и движок пошёл дальше. Оставшееся «2» не подходит ни под одну ветку. Если поставить длинную ветку первой, `12|1` найдёт `['12']`.
</details>

## §6. Квантификаторы: сколько раз

Квантификатор ставится **после** символа, класса или скобок и говорит, сколько раз их повторить.

| | Сколько раз |
|---|---|
| `+` | 1 и больше |
| `*` | 0 и больше |
| `?` | 0 или 1 (то есть «необязательно») |
| `{3}` | ровно 3 |
| `{2,4}` | от 2 до 4 |

**Жадность.** Квантификатор сначала берёт **максимум**, сколько может.

**Числа из диапазона.** Регулярка не знает чисел, только символы. «Число от 0 до 23» нельзя написать напрямую. Нужно выписать все варианты записи и разбить их по первой цифре:
- `00`–`19`: первая цифра 0 или 1, вторая любая → `[01]\d`
- `20`–`23`: первая 2, вторая от 0 до 3 → `2[0-3]`
- вместе: `[01]\d|2[0-3]`

Это главный приём Task1 и Task3. Пока не ограничены края (это будет в §7), проверяем на текстах, где числа стоят отдельно и всегда из двух цифр.

**Упр. 6.1.** Найди числа, у которых может быть минус.
Должно вывести: `['-5', '12']`
```python
print(re.findall(r'???', 'было -5, стало 12'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'-?\d+', 'было -5, стало 12'))
```
`-?` — минус необязателен, `\d+` — одна или больше цифр.
</details>

**Упр. 6.2.** Что найдёт `\d{2,3}`?
Сначала **угадай** вывод, потом запусти:
```python
print(re.findall(r'\d{2,3}', '12345'))
```
<details><summary>Ответ</summary>

`['123', '45']`

Жадность: сначала берётся максимум, 3 цифры. Потом поиск продолжается с «4», остаётся «45».
</details>

**Упр. 6.3.** Найди минуты от `00` до `59` (всегда две цифры).
Должно вывести: `['00', '07', '59']`
```python
print(re.findall(r'???', '00 07 59 60 99'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'[0-5]\d', '00 07 59 60 99'))
```
Первая цифра 0–5, вторая любая.
</details>

**Упр. 6.4.** Найди часы от `00` до `23` (всегда две цифры).
Должно вывести: `['00', '09', '19', '23']`
```python
print(re.findall(r'???', '00 09 19 23 24'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'[01]\d|2[0-3]', '00 09 19 23 24'))
```
Разбор этого шаблона — в теории выше.
</details>

**Упр. 6.5.** Найди месяцы от `01` до `12` (всегда две цифры).
Должно вывести: `['01', '09', '10', '12']`
```python
print(re.findall(r'???', '00 01 09 10 12 13'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'0[1-9]|1[0-2]', '00 01 09 10 12 13'))
```
`01`–`09`: первая 0, вторая 1–9. `10`–`12`: первая 1, вторая 0–2.
</details>

**Упр. 6.6.** Найди время вида `ЧЧ:ММ`, после которого **может** идти `:СС`.
Должно вывести: `['15:00', '17:00:01']`
```python
print(re.findall(r'???', '15:00 и 17:00:01'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'\d\d:\d\d(?::\d\d)?', '15:00 и 17:00:01'))
```
`?` после скобок делает всю группу «двоеточие + две цифры» необязательной. Это каркас Task1.
</details>

## §7. Якоря и границы слова

Якоря не «съедают» символы, они проверяют **место** в строке.

| | Где |
|---|---|
| `^` | начало строки |
| `$` | конец строки |
| `\b` | граница слова: с одной стороны буква/цифра/`_`, с другой — что-то другое или край строки |

Зачем: без границ шаблон часов из §6 найдёт `12` внутри `123`. С `\b` с двух сторон число должно стоять отдельно.

⚠️ Если в шаблоне есть «или», бери его в скобки: `\b(?:1[0-2]|[1-9])\b`. Иначе `\b` прилипнет только к крайним веткам (§5).

**Упр. 7.1.** Найди слово «кот» целиком, но не внутри других слов.
Должно вывести: `['кот', 'кот']`
```python
print(re.findall(r'???', 'кот котлета скот кот.'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'\bкот\b', 'кот котлета скот кот.'))
```
Точка после второго «кот» — не буква, значит, там граница.
</details>

**Упр. 7.2.** Найди числа ровно из двух цифр.
Должно вывести: `['12', '67']`
```python
print(re.findall(r'???', '12 345 67'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'\b\d\d\b', '12 345 67'))
```
В `345` нет границы между 3 и 4, поэтому оно не подходит.
</details>

**Упр. 7.3.** Найди числа от 0 до 59, ведущий ноль необязателен.
Должно вывести: `['5', '05', '59']`
```python
print(re.findall(r'???', '5 05 59 60 123'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'\b[0-5]?\d\b', '5 05 59 60 123'))
```
Без `\b` из «60» нашлось бы «6» и «0», а из «123» — «12» и «3».
</details>

**Упр. 7.4.** Найди месяцы от 1 до 12 без ведущего нуля.
Должно вывести: `['5', '9', '10', '12']`
```python
print(re.findall(r'???', '0 5 9 10 12 13'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'\b(?:1[0-2]|[1-9])\b', '0 5 9 10 12 13'))
```
Длинная ветка первой (§5), «или» в скобках, границы с двух сторон.
</details>

**Упр. 7.5.** Проверь, что строка **целиком** состоит из цифр.
Должно вывести: `True`
```python
print(re.fullmatch(r'???', '2026') is not None)
```
<details><summary>Ответ</summary>

```python
print(re.fullmatch(r'\d+', '2026') is not None)
```
То же самое через `search`: `re.search(r'^\d+$', s)`. `^` и `$` прижимают шаблон к началу и концу строки.
</details>

## §8. Захватывающие группы и обратные ссылки

Обычные скобки `(...)` не только группируют, но и **запоминают** найденное. Группы нумеруются слева направо: 1, 2, …

**Обратная ссылка** `\1` значит «ровно тот же текст, что запомнила группа 1».

⚠️ **Подвох `findall`.** Если в шаблоне есть `(...)`, `findall` возвращает **только содержимое групп**. Чтобы получить совпадение целиком, бери `finditer` и `m.group()`. Скобки `(?:...)` ничего не запоминают и этого подвоха не дают.

**Ключ к Task2:** запомнить первую гласную в группу `(...)`, а дальше разрешить только согласные **или `\1`**, то есть ту же самую гласную.

**Упр. 8.1.** Достань часы и минуты отдельно.
Должно вывести: `('15', '30')`
```python
print(re.search(r'???', 'в 15:30').groups())
```
<details><summary>Ответ</summary>

```python
print(re.search(r'(\d\d):(\d\d)', 'в 15:30').groups())
```
`.groups()` возвращает содержимое всех групп.
</details>

**Упр. 8.2.** Что вернёт `findall` с двумя группами?
Сначала **угадай** вывод, потом запусти:
```python
print(re.findall(r'(\d)(\d)', '1234'))
```
<details><summary>Ответ</summary>

`[('1', '2'), ('3', '4')]`

Пары из групп вместо целых совпадений. Без скобок `\d\d` вернул бы `['12', '34']`.
</details>

**Упр. 8.3.** Найди слова, которые повторяются два раза подряд.
Должно вывести: `['ошибка', 'тут']`
```python
print(re.findall(r'???', 'ошибка ошибка тут тут нет'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'\b(\w+) \1\b', 'ошибка ошибка тут тут нет'))
```
`(\w+)` запоминает слово, `\1` требует то же слово ещё раз. `findall` вернул содержимое группы, то есть одно слово.
</details>

**Упр. 8.4.** Найди слова, которые начинаются и кончаются **одной и той же буквой**.
Должно вывести: `['шалаш', 'ага']`
```python
print([m.group() for m in re.finditer(r'???', 'шалаш папа ага дом')])
```
<details><summary>Ответ</summary>

```python
print([m.group() for m in re.finditer(r'\b(\w)\w*\1\b', 'шалаш папа ага дом')])
```
`(\w)` запоминает **одну** первую букву. Если написать `(\w+)`, пройдёт и «папа» (группа «па»).
</details>

**Упр. 8.5.** Найди слова, где есть две одинаковые буквы подряд.
Должно вывести: `['класс', 'ванна']`
```python
print([m.group() for m in re.finditer(r'???', 'класс ванна дом')])
```
<details><summary>Ответ</summary>

```python
print([m.group() for m in re.finditer(r'\b\w*(\w)\1\w*\b', 'класс ванна дом')])
```
`(\w)\1` — буква и сразу она же.
</details>

## §9. Просмотр вперёд и назад

Проверяет, что **рядом** есть (или нет) какой-то текст, но сам этот текст в совпадение не берёт.

| | Значение |
|---|---|
| `X(?=Y)` | X, **после** которого идёт Y |
| `X(?!Y)` | X, после которого **не** идёт Y |
| `(?<=Y)X` | X, **перед** которым стоит Y |
| `(?<!Y)X` | X, перед которым **не** стоит Y |

Вопросительный знак после открывающей скобки обязателен. В `(?<=...)` и `(?<!...)` текст должен быть фиксированной длины: `(?<!\d)` можно, `(?<!\d+)` нельзя.

Зачем в Task1: шаблон с `\b` в строке `17:00:61` найдёт `17:00`, потому что двоеточие — граница слова. Получится `(TBD):61`, хотя `17:00:61` вообще не время.

**Упр. 9.1.** Найди числа, после которых идёт «кг», без самого «кг».
Должно вывести: `['70']`
```python
print(re.findall(r'???', 'вес 70кг, рост 180см'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'\d+(?=кг)', 'вес 70кг, рост 180см'))
```
`(?=кг)` проверяет, что дальше «кг», но не берёт его в результат.
</details>

**Упр. 9.2.** Найди номер заказа после знака «№».
Должно вывести: `['15']`
```python
print(re.findall(r'???', 'заказ №15, 3 шт'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'(?<=№)\d+', 'заказ №15, 3 шт'))
```
Просмотр назад: перед числом должен стоять «№».
</details>

**Упр. 9.3.** Найди «кот», перед которым **нет** «не ».
Должно вывести: `['кот']`
```python
print(re.findall(r'???', 'не кот, а кот'))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'(?<!не )\bкот\b', 'не кот, а кот'))
```
Первый «кот» отброшен, потому что перед ним «не ». Нашёлся только второй.
</details>

**Упр. 9.4.** Ловушка Task1: что найдёт `\b\d\d:\d\d\b`?
Сначала **угадай** вывод, потом запусти:
```python
print(re.findall(r'\b\d\d:\d\d\b', '17:00:61'))
```
<details><summary>Ответ</summary>

`['17:00']`

Нашлось, хотя `17:00:61` не время. Как это обойти, подсказано в плане (Task1, подсказка 3).
</details>

## §10. Флаги, сборка шаблона, сортировка

**Флаги** — третий аргумент функций `re`:
- `re.I` (`re.IGNORECASE`): без учёта регистра. Обратные ссылки `\1` тоже перестают различать регистр.
- `re.M` (`re.MULTILINE`): `^` и `$` работают на каждой строке текста.
- `re.X` (`re.VERBOSE`): в шаблоне можно ставить пробелы и комментарии.

**Сборка шаблона из кусков** (для Task3). Шаблон — это обычная строка, её можно собрать f-строкой с `rf'...'`:
```python
HOUR = r'(?:[01]\d|2[0-3])'
print(re.findall(rf'\b{HOUR}\b', '07 23 24'))   # ['07', '23']
```
⚠️ В f-строке фигурные скобки квантификаторов надо удваивать (`{{2}}`). Проще в f-строках `{n}` не писать.

**Сортировка по двум признакам** (для Task2):
```python
print(sorted(['bb', 'a', 'ab', 'c'], key=lambda w: (len(w), w)))   # ['a', 'c', 'ab', 'bb']
```
Сначала сравнивается длина, при равной длине — сами слова по алфавиту. Заглавные буквы идут **раньше** строчных, а `ё` — **после** `я`. Если это мешает, сортируй по `w.lower()`.

**Упр. 10.1.** Найди «окно» в любом регистре.
Должно вывести: `['Окно', 'ОКНО', 'окно']`
```python
print(re.findall(r'???', 'Окно ОКНО окно', re.I))
```
<details><summary>Ответ</summary>

```python
print(re.findall(r'окно', 'Окно ОКНО окно', re.I))
```
Флаг `re.I`.
</details>

**Упр. 10.2.** Найди слова, где первая и последняя буква одинаковые, **без учёта регистра**.
Должно вывести: `['Шалаш', 'Ага']`
```python
print([m.group() for m in re.finditer(r'???', 'Шалаш Ага дом', re.I)])
```
<details><summary>Ответ</summary>

```python
print([m.group() for m in re.finditer(r'\b(\w)\w*\1\b', 'Шалаш Ага дом', re.I)])
```
С `re.I` обратная ссылка `\1` считает «Ш» и «ш» одной буквой. Без флага не нашлось бы ничего.
</details>

## §11. Как это работает внутри (для защиты)

- Регулярное выражение можно превратить в **конечный автомат**: состояния и переходы по символам. Строка подходит, если автомат дошёл до принимающего состояния.
- Движок Python (как в Java, Perl, JavaScript) работает **с возвратами (backtracking)**: пробует варианты по очереди и откатывается, если не вышло. Поэтому работают обратные ссылки и просмотр вперёд/назад. Строго говоря, с ними это уже не «регулярные» языки.
- Цена возвратов: плохой шаблон вроде `(a+)+$` на строке `aaaa…ab` работает экспоненциально долго (**катастрофический бэктрекинг**, на этом построены ReDoS-атаки).
- `re.compile(p)` разбирает шаблон один раз и возвращает объект с теми же методами (`.findall`, `.sub`…). Удобно, если шаблон используется много раз.

## §12. Тесты

По заданию на каждую задачу нужно **минимум 5 тестов**. Ответ к каждому ты находишь **сам, без регулярок**, а программа сравнивает его со своим.

Удобная форма:
```python
tests = [
    ('входной текст 1', 'ожидаемый ответ 1'),
    ('входной текст 2', 'ожидаемый ответ 2'),
]
for text, expected in tests:
    got = solve(text)
    print('OK  ' if got == expected else 'FAIL', repr(got))
```
Хорошие тесты покрывают:
1. **пример из задания** (обязательно);
2. **обычный случай** из жизни;
3. **границы**: `00:00`, `23:59:59`, однобуквенное слово;
4. **почти правильное**, что не должно сработать: `24:00`, `12:60`, `ёлка`;
5. **текст без совпадений**.

**Упр. 12.1.** Придумай по одному тесту типов 3 и 4 для Task1 и сам посчитай ответ.
<details><summary>Пример</summary>

- `'Начало в 00:00, конец в 23:59:59'` → `'Начало в (TBD), конец в (TBD)'`
- `'Не время: 24:00 и 12:60'` → строка не меняется.
</details>
