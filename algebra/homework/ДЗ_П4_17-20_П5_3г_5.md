## П4 №17. Расстояние от точки до прямой

**Доказать:** ρ(M, d) = |[M₀M, p]| / |p|, где d задана точкой M₀ и направляющим вектором p.

**Доказательство.**
1. Если M ∈ d, то M₀M ∥ p, [M₀M, p] = 0, и ρ = 0. Формула верна.
2. Пусть M ∉ d. Построим параллелограмм на векторах M₀M и p. Его площадь S = |[M₀M, p]| (геометрический смысл векторного произведения).
3. С другой стороны, S = основание · высота. Основание |p|, высота MH, где H — проекция M на d. То есть S = |p| · ρ(M, d).
4. Приравниваем: |p| · ρ(M, d) = |[M₀M, p]| ⇒ **ρ(M, d) = |[M₀M, p]| / |p|**. ∎

## П4 №18. Расстояние между скрещивающимися прямыми

**Доказать:** ρ(d₁, d₂) = |(M₁M₂, p₁, p₂)| / |[p₁, p₂]|.

**Доказательство.**
1. Проведём через d₁ плоскость α₁ ∥ d₂, через d₂ плоскость α₂ ∥ d₁. Обе плоскости параллельны векторам p₁, p₂, значит α₁ ∥ α₂. Тогда ρ(d₁, d₂) = ρ(α₁, α₂).
2. Построим параллелепипед на векторах M₁M₂, p₁, p₂. Его объём V = |(M₁M₂, p₁, p₂)| (смысл смешанного произведения).
3. С другой стороны, V = S_осн · h. Основание — параллелограмм на p₁, p₂ в α₁: S_осн = |[p₁, p₂]|. Высота — расстояние между α₁ и α₂: h = ρ(d₁, d₂).
4. Приравниваем: ρ(d₁, d₂) · |[p₁, p₂]| = |(M₁M₂, p₁, p₂)| ⇒ **ρ(d₁, d₂) = |(M₁M₂, p₁, p₂)| / |[p₁, p₂]|**. ∎

(Прямые скрещиваются ⇒ p₁ ∦ p₂ ⇒ [p₁, p₂] ≠ 0, делить можно.)

## П4 №19. Расстояние от A(7; 9; 7) до прямой (x−2)/4 = (y−1)/3 = z/2

Из уравнения: M₀(2; 1; 0), p = (4; 3; 2).

**Способ 2 (формула из №17).**
- M₀A = (7−2; 9−1; 7−0) = (5; 8; 7).
- [M₀A, p] = | i j k ; 5 8 7 ; 4 3 2 | = i(8·2 − 7·3) − j(5·2 − 7·4) + k(5·3 − 8·4) = (−5; 18; −17).
- |[M₀A, p]| = √(25 + 324 + 289) = √638.
- |p| = √(16 + 9 + 4) = √29.
- ρ = √638 / √29 = √22.

**Способ 1 (проекция, проверка).**
- Точка прямой: P(t) = (2 + 4t; 1 + 3t; 2t). AP ⊥ p:
  (4t − 5)·4 + (3t − 8)·3 + (2t − 7)·2 = 0 ⇒ 29t − 58 = 0 ⇒ t = 2.
- A′ = (10; 7; 4), AA′ = (3; −2; −3), |AA′| = √(9 + 4 + 9) = √22. ✓

**Ответ: √22.**

## П4 №20. Расстояние между скрещивающимися прямыми

d₁: x = −4t, y = −1 + 3t, z = −2 − t ⇒ M₁(0; −1; −2), p₁ = (−4; 3; −1).
d₂: x = 4 − 2t, y = 1 − t, z = 1 − 3t ⇒ M₂(4; 1; 1), p₂ = (−2; −1; −3).

**Способ 2 (формула из №18).**
- M₁M₂ = (4; 2; 3).
- [p₁, p₂] = | i j k ; −4 3 −1 ; −2 −1 −3 | = i(3·(−3) − (−1)(−1)) − j((−4)(−3) − (−1)(−2)) + k((−4)(−1) − 3·(−2)) = (−10; −10; 10).
- |[p₁, p₂]| = √300 = 10√3.
- (M₁M₂, p₁, p₂) = M₁M₂ · [p₁, p₂] = 4·(−10) + 2·(−10) + 3·10 = −30 ≠ 0 ⇒ прямые действительно скрещиваются.
- ρ = |−30| / (10√3) = 3/√3 = √3.

**Способ 1 (плоскость, проверка).**
- Плоскость через d₁, параллельная d₂: нормаль n = [p₁, p₂] ∥ (1; 1; −1), точка M₁:
  (x − 0) + (y + 1) − (z + 2) = 0 ⇒ x + y − z − 1 = 0.
- Расстояние от M₂(4; 1; 1): |4 + 1 − 1 − 1| / √3 = 3/√3 = √3. ✓

**Ответ: √3.**

## П5 №3(г). Парабола x² = −y

Каноническая форма с осью Oy: x² = −2py.
- 2p = 1 ⇒ **p = 1/2**.
- Вершина O(0; 0), ось симметрии — **Oy**, ветви **вниз** (y ≤ 0).
- Фокус F(0; −p/2) = (0; −1/4), директриса y = p/2 = 1/4.

## П5 №5. Парабола, симметричная относительно Ox, через A(2; 3) и O(0; 0)

- Проходит через O и симметрична относительно Ox ⇒ вершина в O, ось Ox: y² = 2px.
- Подставляем A(2; 3): 9 = 2p·2 ⇒ p = 9/4.
- **Ответ: y² = 9x/2** (p = 9/4, фокус (9/8; 0), директриса x = −9/8, ветви вправо).
