## Шпаргалка по формулам
- **Общее уравнение:** $Ax + By + C = 0$, вектор нормали $\vec n = (A, B)$ перпендикулярен прямой.
- **Через точку $(x_0,y_0)$ с направляющим вектором $\vec p = (m, l)$:** $\dfrac{x-x_0}{m} = \dfrac{y-y_0}{l}$.
- **Через точку с нормалью $(A,B)$:** $A(x-x_0) + B(y-y_0) = 0$.
- **Взаимное расположение** прямых $A_1x+B_1y+C_1=0$ и $A_2x+B_2y+C_2=0$:
  - $\frac{A_1}{A_2} \ne \frac{B_1}{B_2}$ → **пересекаются** (решаем систему);
  - $\frac{A_1}{A_2} = \frac{B_1}{B_2} \ne \frac{C_1}{C_2}$ → **параллельны**;
  - $\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2}$ → **совпадают**.

## №3 б) через начало координат и A(2, 5)
<details><summary>Решение</summary>

Направляющий вектор $\vec{OA} = (2, 5)$: $\frac{x}{2} = \frac{y}{5}$ → **$5x - 2y = 0$** (или $y = \frac52 x$).
Проверка: A: $5\cdot2 - 2\cdot5 = 0$ ✓.
</details>

## №3 г) через A(1, −4) параллельно вектору p = (2, −3)
<details><summary>Решение</summary>

$\frac{x-1}{2} = \frac{y+4}{-3}$ → $-3(x-1) = 2(y+4)$ → $-3x + 3 = 2y + 8$ → **$3x + 2y + 5 = 0$**.
Проверка: A: $3 - 8 + 5 = 0$ ✓. Нормаль $(3, 2)$ перпендикулярна $\vec p$: $3\cdot2 + 2\cdot(-3) = 0$ ✓.
</details>

## №14 прямая через начало координат, у нормали координаты равны
<details><summary>Решение</summary>

$\vec n = (a, a)$, $a \ne 0$. Прямая через $O$: $a x + a y = 0$ → **$x + y = 0$**.
</details>

## №15 как прямые расположены относительно осей
Подсказка: $C = 0$ → проходит через начало координат; нет $y$ → параллельна $Oy$; нет $x$ → параллельна $Ox$.

<details><summary>Решение</summary>

| | Прямая | Вывод |
|---|---|---|
| а | $2x - 3y = 0$ | проходит через **начало координат** ($C = 0$) |
| б | $3x - y + 1 = 0$ | общее положение: пересекает $Ox$ в $x = -\frac13$, $Oy$ в $y = 1$ |
| в | $5x - 1 = 0$ | $x = \frac15$: **параллельна оси $Oy$** |
| г | $3y + 1 = 0$ | $y = -\frac13$: **параллельна оси $Ox$** |
| д | $x + 2y = 0$ | проходит через **начало координат** |
| е | $6x = 0$ | $x = 0$: **совпадает с осью $Oy$** |
</details>

## №16 в–ж взаимное расположение пар прямых

<details><summary>в) (√3/2)x − 3y + √3 = 0 и x − 2√3y + 2 = 0</summary>

Умножим первое на $\frac{2}{\sqrt3}$: $x - \frac{6}{\sqrt3}y + 2 = x - 2\sqrt3\,y + 2 = 0$ — это ровно второе уравнение. **Прямые совпадают.**
</details>

<details><summary>г) y = 3 и x + y = 0</summary>

Подставим $y = 3$: $x = -3$. **Пересекаются в точке $(-3;\ 3)$.**
</details>

<details><summary>д) x + y + 1 = 0 и x + y − 1 = 0</summary>

$\frac11 = \frac11 \ne \frac{1}{-1}$ → **параллельны** (общих точек нет).
</details>

<details><summary>е) x = 0 и x + 3 = 0</summary>

Обе вертикальные: $x = 0$ и $x = -3$. **Параллельны.**
</details>

<details><summary>ж) √5x − 3y + 1 = 0 и (5/3)x − √5y + √5/3 = 0</summary>

Умножим второе на $\frac{3}{\sqrt5}$: $\frac{5}{\sqrt5}x - 3y + 1 = \sqrt5\,x - 3y + 1 = 0$ — это первое уравнение. **Прямые совпадают.**
</details>
