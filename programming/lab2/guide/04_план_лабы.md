## Шаг 1. Первый покемон — Golett (15 мин)
`src/pokemons/Golett.java`:
- `package pokemons;`, импорт библиотеки;
- `public class Golett extends Pokemon` — **не** `final`: от него будет Golurk;
- конструктор `(String name, int level)`: `super(...)`, `setType(...)` с двумя типами, `setStats(...)` из таблицы в `01`.

В `Main` добавь Golett'а в бой вместо одного из «пустых».

<details><summary>Подсказка: каркас конструктора</summary>

```java
public Golett(String name, int level) {
    super(name, level);
    setType(Type.???, Type.???);
    setStats(??, ??, ??, ??, ??, ??);
}
```
</details>

✅ В бою появилось `Golett <имя>` (атак пока нет — он тоже «борется»).

## Шаг 2. Первая атака — Shadow Ball (20 мин)
`src/moves/ShadowBall.java`:
- `package moves;`
- категория Special → `extends SpecialMove`; это «лист» → `final`;
- конструктор без параметров: `super(Type.???, power, accuracy)`;
- `@Override applyOppEffects(Pokemon p)`: с вероятностью 20% понизить Sp.Def на 1;
- `@Override describe()`: вернуть текст, например `"бросает Shadow Ball"`.

В `Golett` после `setStats` — `setMove(new ShadowBall());` (+ `import moves.*;`).

<details><summary>Подсказка: эффект с вероятностью</summary>

```java
if (Math.random() < 0.2) {
    p.setMod(Stat.SPECIAL_DEFENSE, -1);
}
```
</details>

✅ В бою Golett использует твою атаку, и иногда появляется сообщение о снижении характеристики.

## Шаг 3. Остальные атаки Golett (20 мин)
- **Low Sweep** — `PhysicalMove`, эффект на цель: Speed −1 (всегда).
- **Rock Polish** — `StatusMove`, эффект на **себя**: Speed +2. Какой метод? (см. `03`, §3)

Для StatusMove сила не важна — передай `0`.

✅ Golett в бою чередует 3 атаки.

## Шаг 4. Эволюция — Golurk (15 мин)
- `public final class Golurk extends Golett`.
- В конструкторе: `super(name, level)` — **и всё, что делает Golett, выполнится само**.
- Свои `setStats(...)`.
- Новая атака **Flash Cannon** — **`addMove`**, не `setMove`. Почему? (Ответ: `setMove` затрёт 3 унаследованные атаки.)
- Тип ставить заново не нужно — он уже от Golett.

✅ У Golurk в бою 4 атаки: 3 от Golett + Flash Cannon.

## Шаг 5. Цепочка Flabebe → Floette → Florges (40 мин)
Повтори схему шагов 1–4:
- **Flabebe** (`extends Pokemon`, не final): FAIRY, атаки **Dazzling Gleam** (Special, без эффекта) и **Facade**.
- **Floette** (`extends Flabebe`, не final): свои статы + `addMove(VineWhip)`.
- **Florges** (`extends Floette`, **final**): свои статы + `addMove(DisarmingVoice)`.

Особые атаки:
- **Disarming Voice** — никогда не промахивается.
- **Facade** — сила удваивается, если атакующий обожжён, отравлен или парализован.

<details><summary>Подсказка: «никогда не промахивается»</summary>

Переопредели `protected boolean checkAccuracy(Pokemon att, Pokemon def)` и верни `true`.
</details>

<details><summary>Подсказка: Facade</summary>

Урон считается в `DamageMove`. Метод `calcBaseDamage(Pokemon att, Pokemon def)` можно переопределить:
вызови `super.calcBaseDamage(att, def)`, и если `att.getCondition()` равен одному из трёх нужных `Status`, умножь результат на 2.
</details>

## Частые ошибки (заранее)

| Ошибка компиляции | Причина |
|---|---|
| `cannot find symbol: class Pokemon` | нет `-cp .../Pokemon.jar` или нет `import ru.ifmo.se.pokemon.*;` |
| `cannot find symbol: class ShadowBall` | нет `import moves.*;` в покемоне |
| `setType(...) has protected access` | пытаешься вызвать из `Main` — нужно из конструктора покемона |
| `call to super must be first statement` | `super(...)` не первой строкой |
| `cannot inherit from final Golett` | случайно сделал промежуточный класс `final` |
| `attempting to assign weaker access privileges` | `describe()` или `applyOppEffects` объявлен `private` |
| `Could not find or load main class Main` | запускать нужно `lab2.Main`, с `out` в classpath |
