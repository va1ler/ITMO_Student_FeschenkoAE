## Шпаргалка: всё, что нужно знать про покемонов (без этого не понять комментарии)

- **Тип** (`Type`) — стихия: огонь, вода, призрак… Атака своего типа бьёт сильнее, а некоторые типы не действуют на другие (атака NORMAL не действует на GHOST). Всё это библиотека считает сама.
- **6 характеристик** в порядке `setStats(hp, attack, defense, spAttack, spDefense, speed)`: здоровье, атака, защита, спец. атака, спец. защита, скорость.
- **Атака бывает трёх видов** (это определяет, от какого класса наследоваться):
  - **физическая** → `PhysicalMove` (урон зависит от атаки и защиты);
  - **специальная** → `SpecialMove` (урон зависит от спец. атаки и спец. защиты);
  - **статусная** → `StatusMove` (урона нет, только эффект).
- **Сила** (power) — насколько сильно бьёт. У статусных 0.
- **Точность** (accuracy) — доля: `1` = всегда попадает (если не мешают эффекты), `0.7` = в 70 % случаев.
- **Эффект** — что ещё делает атака: меняет характеристику на ±N (`p.setMod(Stat.SPEED, -1)`) или накладывает состояние (`Effect.paralyze(p)` — паралич).
- **Эволюция** — покемон «вырастает» в следующую форму. В коде это наследование: следующая форма `extends` предыдущей.

## Шаг 7. Финальный `Main`

Нужно: две команды, все 6 покемонов, у каждого имя (любое, можно смешное), уровни по таблице.

| Покемон | Уровень | Почему |
|---|---|---|
| Thundurus, Golett, Flabebe | 1 | атаки выдаются дисками (TM) на любом уровне |
| Golurk | 43 | Golett эволюционирует в Golurk на 43 уровне |
| Floette, Florges | 19 | Flabebe эволюционирует в Floette на 19 уровне |

```java
package lab2;

import pokemons.*;
import ru.ifmo.se.pokemon.*;

public class Main {
    public static void main(String[] args) {
        Battle b = new Battle();
        b.addAlly(new Golurk("Гигант", 43));
        b.addAlly(new Flabebe("Малыш", 1));
        b.addFoe(new Thundurus("Гром", 1));
        b.addFoe(new Golett("Голем", 1));
        b.addFoe(new Floette("Цветок", 19));
        b.addFoe(new Florges("Королева", 19));
        b.go();
    }
}
```
Это я дал целиком: тут нет новой Java, а составы команд — дело вкуса. Имена поменяй на свои.

Golurk на 43 уровне намного сильнее остальных (они 1 и 19 уровня), поэтому его команда почти всегда побеждает. Задание этого не запрещает. Бой идёт медленно, около 15 секунд: библиотека специально делает паузы между ходами.

✅ Бой доходит до «The team … wins the battle!», в выводе встречаются твои тексты атак.

## Частые ошибки

| Ошибка компиляции | Причина |
|---|---|
| `cannot find symbol: class Pokemon` | нет `import ru.ifmo.se.pokemon.*;` или jar не подключён |
| `cannot find symbol: class ShadowBall` | в покемоне нет `import moves.*;` |
| `cannot find symbol: class Golett` | в `Main` нет `import pokemons.*;` |
| `setType(...) has protected access` | вызываешь из `Main` — нужно в конструкторе покемона |
| `call to super must be first statement` | `super(...)` не первой строкой |
| `cannot inherit from final Golett` | промежуточный класс случайно сделал `final` |
| `method does not override ...` | опечатка в имени крючка (`applyOpEffects` вместо `applyOppEffects`) |
| `attempting to assign weaker access privileges` | крючок объявлен `private` или без модификатора, а нужно `protected` |
