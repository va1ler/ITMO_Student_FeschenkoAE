## 0. Каркас любой программы
```java
public class Main {                            // класс; имя = имя файла (Main.java)
    public static void main(String[] args) {   // точка входа: отсюда JVM начинает выполнение
        System.out.println("Привет, helios!");  // печать строки + перенос
    }
}
```
- `public class Main`: весь код в Java живёт внутри классов. Имя public-класса обязано совпадать с именем файла.
- `public static void main(String[] args)`: именно этот метод ищет JVM при запуске. `args` — аргументы командной строки.
- IntelliJ сгенерировала тебе `void main()` без класса и `IO.println`. Это новинки Java 25, **в Java 21 так нельзя**. Всегда пиши классический вариант, как выше.

## 1. Переменные и примитивные типы
```java
int a = 5;           // целое, 32 бита
long big = 16L;      // целое, 64 бита (L на конце — литерал типа long)
double x = 2.5;      // дробное, 64 бита
boolean ok = true;   // true / false
```
8 примитивных типов: `byte`(8 бит), `short`(16), `int`(32), `long`(64), `float`(32), `double`(64), `char`(16, беззнаковый, код символа Unicode), `boolean`.

**Декларация, инициализация и присваивание:**
```java
int k;       // декларация: объявили, значения ещё нет (использовать нельзя!)
k = 3;       // первое присваивание = инициализация
k = k + 1;   // присваивание нового значения
```

**Приведение типов:**
```java
int i = 7;
double d = i;            // расширяющее (без потерь) — происходит автоматически
double y = 9.99;
int t = (int) y;         // сужающее — только явно, дробная часть отбрасывается → 9
```

**Главная ловушка:**
```java
System.out.println(3 / 4);     // 0     ← int / int = целочисленное деление
System.out.println(3.0 / 4);   // 0.75  ← если хотя бы одно число double, деление дробное
```

## 2. Класс `Math`
Всё вызывается как `Math.имя(аргументы)`:

| Функция | Что делает | Пример |
|---|---|---|
| `Math.pow(a, b)` | aᵇ | `Math.pow(2, 10)` → 1024.0 |
| `Math.sqrt(a)` | √a | `Math.sqrt(16)` → 4.0 |
| `Math.cbrt(a)` | ∛a (работает и с отрицательными) | `Math.cbrt(-8)` → −2.0 |
| `Math.exp(a)` | eᵃ | `Math.exp(1)` → 2.718… |
| `Math.sin/cos/tan(a)` | тригонометрия, a в **радианах** | `Math.cos(0)` → 1.0 |
| `Math.asin/acos/atan(a)` | обратная тригонометрия | `Math.asin(1)` → 1.5707… |
| `Math.log(a)` | натуральный логарифм ln | |
| `Math.abs(a)` | модуль | |
| `Math.random()` | случайное число в [0; 1) | |
| `Math.PI`, `Math.E` | константы π и e | |

Особые значения `double`: `Infinity` (1.0/0), `-Infinity`, `NaN` («не число», например 0.0/0 или `Math.sqrt(-1)`).

## 3. Операторы и приоритеты (от высшего к низшему)
1. `()`, доступ `[]` и `.`
2. унарные: `++ -- ! -` и приведение `(int)`
3. `* / %`
4. `+ -`
5. сравнения `< > <= >=`, затем `== !=`
6. логические `&&`, затем `||`
7. тернарный `? :`
8. присваивания `= += -= ...` (выполняются **справа налево**)

`a / b / c` читается как `(a / b) / c`: операторы одного уровня выполняются слева направо.

## 4. Условия: `if / else if / else`
```java
long v = 12;
if (v == 10) {
    System.out.println("десять");
} else if (v == 8 || v == 12 || v == 16) {   // || — «ИЛИ»
    System.out.println("8, 12 или 16");
} else {
    System.out.println("что-то другое");
}
```
Есть ещё `switch`, он сравнивает одно значение с набором констант. С `long` switch **не работает** (только `int`, `char`, `short`, `byte`, `String`, `enum`), поэтому в лабе используем `if`.

## 5. Циклы
```java
for (int i = 0; i < 5; i++) {      // инициализация; условие; шаг
    System.out.println(i);         // 0 1 2 3 4
}

int k = 0;
while (k < 3) { k++; }             // проверка ДО тела

do { k--; } while (k > 0);         // тело выполнится хотя бы 1 раз
```

## 6. Массивы
```java
long[] l = new long[7];            // 7 элементов, все = 0
double[] arr = {1.5, 2.0, 3.7};    // сразу со значениями
arr[0] = 10;                        // индексы с 0 до length-1
System.out.println(arr.length);     // 3

double[][] m = new double[7][19];   // двумерный: 7 строк, в каждой 19 элементов
m[2][5] = 3.14;                     // строка 2, столбец 5
System.out.println(m.length);       // 7  — число строк
System.out.println(m[0].length);    // 19 — длина строки
```
Двумерный массив в Java — это **массив массивов**: `m[i]` сам является массивом `double[]`.

Массив — **ссылочный** тип. Переменная хранит не сами числа, а ссылку на место в памяти, где они лежат. Выход за границы (`arr[3]` при длине 3) выбросит `ArrayIndexOutOfBoundsException`.

## 7. Методы (подпрограммы)
```java
public class Main {
    public static void main(String[] args) {
        double r = square(3.0);          // вызов: 3.0 копируется в параметр a
        System.out.println(r);           // 9.0
        greet("Саша");
    }

    public static double square(double a) {   // тип результата, имя, параметры
        return a * a;                         // return отдаёт результат
    }

    public static void greet(String name) {   // void = ничего не возвращает
        System.out.println("Привет, " + name);
    }
}
```
- `static` означает, что метод принадлежит классу и вызывается без создания объекта. Пока все наши методы static.
- Параметры-примитивы передаются **по значению**: метод получает копию, и её изменение не трогает оригинал.

## 8. Форматированный вывод `printf`
```java
double v = 3.14159;
System.out.printf("%.3f%n", v);      // 3.142 (или 3,142 в русской локали)
System.out.printf("%10.3f|%n", v);   //      3.142|   ← ширина 10, выравнивание вправо
System.out.printf("%-10.3f|%n", v);  // 3.142     |   ← минус = влево
System.out.printf("%d шт.%n", 7);    // %d — целое
System.out.printf("%e%n", v);        // 3.141590e+00 — экспоненциальная запись
```
`%n` — перенос строки (как `\n`, только правильный для любой ОС).
